    10.2: React Hook Form, Validaciones Zod y Accesibilidad WAI-ARIA

    1. Arquitectura de React Hook Form y Optimización \(O(1)\)

    A medida que las aplicaciones web escalan, la gestión manual de formularios mediante useState genera problemas de rendimiento por re-renderizados masivos y de mantenibilidad del código. Cada pulsación de tecla en un componente controlado fuerza el re-renderizado de todo el árbol del formulario, alcanzando una complejidad de tiempo y ejecución de renderizado de \(O(N)\), donde \(N\) es el número de componentes dependientes.

    React Hook Form (RHF) resuelve este problema adoptando una arquitectura basada en componentes no controlados con suscripciones aisladas. Los elementos HTML del DOM se registran mediante referencias (ref), e imponen re-renderizados exclusivamente sobre los nodos que cambian de estado o muestran mensajes de error, logrando un rendimiento de \(O(1)\) por pulsación.

    1.1. Core API de React Hook Form

    El hook useForm expone un conjunto de funciones y objetos clave para la gestión declarativa del ciclo de vida del formulario:

    • register: Función que vincula un nodo del DOM a React Hook Form mediante la inyección de las propiedades name, ref, onChange y onBlur.
    • handleSubmit: Función de orden superior (HOF) que intercepta el evento de envío, ejecuta las validaciones y, si no hay errores, pasa los datos fuertemente tipados a la función de callback personalizada.
    • formState: Objeto reactivo que contiene información sobre el estado del formulario:
    • errors: Contiene los errores de validación por campo.
    • isSubmitting: Booleano que indica si la acción asíncrona de envío está en ejecución.
    • isDirty: Indica si el usuario ha modificado algún campo respecto a los valores iniciales (defaultValues).

    • touchedFields: Objeto que rastrea los campos con los que el usuario ha interactuado (foco y pérdida de foco).

    • reset: Restablece los valores del formulario a sus valores iniciales o a un nuevo estado.

    • **setError / clearErrors**: Permiten manipular imperativamente el estado de error (util para errores devueltos por la API REST del servidor).

    2. Validaciones Declarativas con Zod e Inferencia de Tipos (z.infer)

    Zod es una librería de declaración y validación de esquemas con prioridad en TypeScript (TypeScript-first). Permite definir la estructura de los datos de entrada una sola vez y extraer automáticamente el tipo estático de TypeScript, eliminando la duplicidad entre tipos y validaciones en tiempo de ejecución.

    2.1. Definición de Esquema y Validación Cruzada con .refine()

    A través del paquete @hookform/resolvers/zod, conectamos la potencia declarativa de Zod con la gestión de estado de React Hook Form.

    import { z } from 'zod';

// 1. Definición del Esquema de Validación Zod
export const registroUsuarioSchema = z
  .object({
    nombreCompleto: z
      .string()
      .min(3, { message: 'El nombre debe tener al menos 3 caracteres.' })
      .max(50, { message: 'El nombre no puede superar los 50 caracteres.' }),

    email: z
      .string()
      .min(1, { message: 'El correo electrónico es obligatorio.' })
      .email({ message: 'Proporcione una dirección de correo válida.' }),

    password: z
      .string()
      .min(8, { message: 'La contraseña debe tener un mínimo de 8 caracteres.' })
      .regex(/[A-Z]/, { message: 'Debe contener al menos una letra mayúscula.' })
      .regex(/[0-9]/, { message: 'Debe contener al menos un número.' }),

    confirmarPassword: z.string(),

    rol: z.enum(['desarrollador', 'disenador', 'project_manager'], {
      errorMap: () => ({ message: 'Seleccione un rol válido de la lista.' }),
    }),

    edad: z.coerce
      .number({ invalid_type_error: 'La edad debe ser un número.' })
      .min(18, { message: 'Debe ser mayor de 18 años para registrarse.' })
      .max(99, { message: 'Edad no válida.' }),

    aceptaTerminos: z.boolean().refine((val) => val === true, {
      message: 'Debe aceptar los términos y condiciones.',
    }),
  })
  // Validaciones Cruzadas (Campos dependientes)
  .refine((data) => data.password === data.confirmarPassword, {
    message: 'Las contraseñas no coinciden.',
    path: ['confirmarPassword'], // El error se asociará al campo confirmarPassword
  });

// 2. Inferencia Automática de Tipos TypeScript
export type RegistroUsuarioFormInput = z.infer<typeof registroUsuarioSchema>;

    3. Integración de Componentes de UI mediante <Controller/>

    En aplicaciones modernas es habitual utilizar librerías de componentes UI de terceros (como Radix UI, Shadcn/ui, React Select o Headless UI) cuyos componentes no exponen directamente un elemento nativo <input> ni aceptan la prop ref estándar.

    Para estos casos, React Hook Form ofrece el componente wrapper <Controller/> (o el hook useController), que actúa como un puente entre la gestión interna del estado de RHF y el componente de UI controlado.

    import { Controller, Control } from 'react-hook-form';
import { RegistroUsuarioFormInput } from './registroSchema';

interface SelectorRolProps {
  control: Control<RegistroUsuarioFormInput>;
  error?: string;
}

export function SelectorRolPersonalizado({ control, error }: SelectorRolProps) {
  return (
    <div className="space-y-1">
      <label htmlFor="rol-select" className="block text-sm font-medium text-slate-700">
        Rol Profesional:
      </label>
      <Controller
        name="rol"
        control={control}
        render={({ field: { onChange, value, name, ref } }) => (
          // Componente personalizado o de librería de terceros
          <select
            id="rol-select"
            name={name}
            ref={ref}
            value={value || ''}
            onChange={onChange}
            className={`w-full px-3 py-2 border rounded-lg focus:outline-none focus:ring-2 ${
              error ? 'border-red-500 focus:ring-red-200' : 'border-slate-300 focus:ring-blue-500'
            }`}
          >
            <option value="" disabled>-- Seleccione un rol --</option>
            <option value="desarrollador">Desarrollador / Desarrolladora</option>
            <option value="disenador">Diseñador / Diseñadora UI/UX</option>
            <option value="project_manager">Project Manager</option>
          </select>
        )}
      />
      {error && <p className="text-xs text-red-600 mt-1">{error}</p>}
    </div>
  );
}

    4. Accesibilidad (WAI-ARIA) y Experiencia de Usuario (UX)

    La gestión de formularios debe cumplir los estándares de accesibilidad WAI-ARIA para garantizar su uso mediante tecnologías de asistencia (como lectores de pantalla) y navegación exclusiva por teclado.

    4.1. Patrones de Accesibilidad Esenciales en Formularios

    • **htmlFor y id**: Todo elemento <label> debe vincularse de manera unívoca al id de su <input> correspondiente.
    • aria-invalid: Atributo booleano (true/false) que notifica al lector de pantalla si el valor del campo viola una regla de validación.
    • aria-describedby: Apunta al id del elemento contenedor del mensaje de error o texto de ayuda, garantizando que el lector de pantalla lea el error en cuanto el usuario enfoca el campo no válido.
    • aria-live="polite": Utilizado en contenedores de alerta global para anunciar cambios sin interrumpir la lectura en curso del usuario.
    • Gestión del Foco: React Hook Form coloca automáticamente el foco en el primer campo no válido al enviar el formulario si la validación falla.
    // Ejemplo de estructuración accesible de un campo de texto
<div>
  <label htmlFor="email" className="block text-sm font-medium text-slate-700">
    Correo Electrónico:
  </label>
  <input
    id="email"
    type="email"
    aria-invalid={errors.email ? 'true' : 'false'}
    aria-describedby={errors.email ? 'email-error' : undefined}
    {...register('email')}
    className="w-full px-3 py-2 border rounded-md"
  />
  {errors.email && (
    <p id="email-error" className="text-sm text-red-600 mt-1" role="alert">
      {errors.email.message}
    </p>
  )}
</div>

    5. Demostración Práctica Completa: Formulario Profesional de Registro

    A continuación se muestra una implementación en React con TypeScript que integra React Hook Form, Zod, resolvers, Tailwind CSS, componentes dinámicos con <Controller/> y atributos WAI-ARIA:

    import React, { useState } from 'react';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { registroUsuarioSchema, RegistroUsuarioFormInput } from './registroSchema';
import { SelectorRolPersonalizado } from './SelectorRolPersonalizado';

export function FormularioRegistroProfesional() {
  const [servidorError, setServidorError] = useState<string | null>(null);
  const [registroExitoso, setRegistroExitoso] = useState<boolean>(false);

  const {
    register,
    handleSubmit,
    control,
    reset,
    formState: { errors, isSubmitting, isValid, isDirty },
  } = useForm<RegistroUsuarioFormInput>({
    resolver: zodResolver(registroUsuarioSchema),
    mode: 'onBlur', // Modos de validación: onChange | onBlur | onSubmit | touched
    defaultValues: {
      nombreCompleto: '',
      email: '',
      password: '',
      confirmarPassword: '',
      rol: undefined,
      edad: 18,
      aceptaTerminos: false,
    },
  });

  const onSubmitHandler = async (data: RegistroUsuarioFormInput) => {
    setServidorError(null);
    setRegistroExitoso(false);

    try {
      // Simulación de llamada asíncrona a la API REST (Server Delay)
      await new Promise((resolve) => setTimeout(resolve, 2000));

      // Simulación de error de red o backend
      if (data.email === 'error@test.com') {
        throw new Error('El correo electrónico ya está registrado en la plataforma.');
      }

      console.log('Payload procesado y validado enviado al servidor:', data);
      setRegistroExitoso(true);
      reset(); // Limpia los campos tras el registro exitoso
    } catch (err: unknown) {
      if (err instanceof Error) {
        setServidorError(err.message);
      } else {
        setServidorError('Ocurrió un error inesperado al procesar la solicitud.');
      }
    }
  };

  return (
    <div className="max-w-xl mx-auto my-10 p-8 bg-white border border-slate-200 rounded-2xl shadow-xl">
      <header className="mb-6">
        <h1 className="text-2xl font-bold text-slate-900">Crear una Cuenta</h1>
        <p className="text-sm text-slate-500">Ingrese sus datos para completar el registro.</p>
      </header>

      {/* Banner de Mensaje Global de Error del Servidor */}
      {servidorError && (
        <div
          role="alert"
          aria-live="polite"
          className="mb-6 p-4 bg-red-50 border-l-4 border-red-500 rounded-r-md"
        >
          <div className="flex">
            <p className="text-sm font-medium text-red-800">{servidorError}</p>
          </div>
        </div>
      )}

      {/* Banner de Éxito */}
      {registroExitoso && (
        <div
          role="status"
          aria-live="polite"
          className="mb-6 p-4 bg-emerald-50 border-l-4 border-emerald-500 rounded-r-md"
        >
          <p className="text-sm font-medium text-emerald-800">
            ¡Usuario registrado con éxito! Se ha enviado un correo de confirmación.
          </p>
        </div>
      )}

      <form onSubmit={handleSubmit(onSubmitHandler)} noValidate className="space-y-5">
        {/* Nombre Completo */}
        <div>
          <label htmlFor="nombreCompleto" className="block text-sm font-medium text-slate-700 mb-1">
            Nombre Completo:
          </label>
          <input
            id="nombreCompleto"
            type="text"
            aria-invalid={errors.nombreCompleto ? 'true' : 'false'}
            aria-describedby={errors.nombreCompleto ? 'nombreCompleto-error' : undefined}
            {...register('nombreCompleto')}
            className={`w-full px-3.5 py-2 border rounded-lg transition-colors focus:outline-none focus:ring-2 ${
              errors.nombreCompleto
                ? 'border-red-500 focus:ring-red-200'
                : 'border-slate-300 focus:ring-blue-500'
            }`}
            placeholder="Ej. María García"
          />
          {errors.nombreCompleto && (
            <p id="nombreCompleto-error" role="alert" className="text-xs text-red-600 mt-1">
              {errors.nombreCompleto.message}
            </p>
          )}
        </div>

        {/* Email */}
        <div>
          <label htmlFor="email" className="block text-sm font-medium text-slate-700 mb-1">
            Correo Electrónico:
          </label>
          <input
            id="email"
            type="email"
            aria-invalid={errors.email ? 'true' : 'false'}
            aria-describedby={errors.email ? 'email-error' : undefined}
            {...register('email')}
            className={`w-full px-3.5 py-2 border rounded-lg transition-colors focus:outline-none focus:ring-2 ${
              errors.email
                ? 'border-red-500 focus:ring-red-200'
                : 'border-slate-300 focus:ring-blue-500'
            }`}
            placeholder="usuario@dominio.com"
          />
          {errors.email && (
            <p id="email-error" role="alert" className="text-xs text-red-600 mt-1">
              {errors.email.message}
            </p>
          )}
        </div>

        {/* Contraseñas (Grupo Grid) */}
        <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
          <div>
            <label htmlFor="password" className="block text-sm font-medium text-slate-700 mb-1">
              Contraseña:
            </label>
            <input
              id="password"
              type="password"
              aria-invalid={errors.password ? 'true' : 'false'}
              aria-describedby={errors.password ? 'password-error' : undefined}
              {...register('password')}
              className={`w-full px-3.5 py-2 border rounded-lg transition-colors focus:outline-none focus:ring-2 ${
                errors.password
                  ? 'border-red-500 focus:ring-red-200'
                  : 'border-slate-300 focus:ring-blue-500'
              }`}
            />
            {errors.password && (
              <p id="password-error" role="alert" className="text-xs text-red-600 mt-1">
                {errors.password.message}
              </p>
            )}
          </div>

          <div>
            <label htmlFor="confirmarPassword" className="block text-sm font-medium text-slate-700 mb-1">
              Confirmar Contraseña:
            </label>
            <input
              id="confirmarPassword"
              type="password"
              aria-invalid={errors.confirmarPassword ? 'true' : 'false'}
              aria-describedby={errors.confirmarPassword ? 'confirmarPassword-error' : undefined}
              {...register('confirmarPassword')}
              className={`w-full px-3.5 py-2 border rounded-lg transition-colors focus:outline-none focus:ring-2 ${
                errors.confirmarPassword
                  ? 'border-red-500 focus:ring-red-200'
                  : 'border-slate-300 focus:ring-blue-500'
              }`}
            />
            {errors.confirmarPassword && (
              <p id="confirmarPassword-error" role="alert" className="text-xs text-red-600 mt-1">
                {errors.confirmarPassword.message}
              </p>
            )}
          </div>
        </div>

        {/* Integración de Componente UI Controlado con Controller */}
        <SelectorRolPersonalizado control={control} error={errors.rol?.message} />

        {/* Campo Edad (Coerción a Número) */}
        <div>
          <label htmlFor="edad" className="block text-sm font-medium text-slate-700 mb-1">
            Edad:
          </label>
          <input
            id="edad"
            type="number"
            aria-invalid={errors.edad ? 'true' : 'false'}
            aria-describedby={errors.edad ? 'edad-error' : undefined}
            {...register('edad')}
            className={`w-full px-3.5 py-2 border rounded-lg transition-colors focus:outline-none focus:ring-2 ${
              errors.edad
                ? 'border-red-500 focus:ring-red-200'
                : 'border-slate-300 focus:ring-blue-500'
            }`}
          />
          {errors.edad && (
            <p id="edad-error" role="alert" className="text-xs text-red-600 mt-1">
              {errors.edad.message}
            </p>
          )}
        </div>

        {/* Checkbox Accesible de Términos */}
        <div className="flex items-start space-x-3 pt-2">
          <input
            id="aceptaTerminos"
            type="checkbox"
            aria-invalid={errors.aceptaTerminos ? 'true' : 'false'}
            aria-describedby={errors.aceptaTerminos ? 'aceptaTerminos-error' : undefined}
            {...register('aceptaTerminos')}
            className="mt-1 h-4 w-4 text-blue-600 border-slate-300 rounded focus:ring-blue-500"
          />
          <div>
            <label htmlFor="aceptaTerminos" className="text-sm text-slate-600 leading-snug">
              Acepto la política de privacidad y los términos de servicio.
            </label>
            {errors.aceptaTerminos && (
              <p id="aceptaTerminos-error" role="alert" className="text-xs text-red-600 mt-0.5">
                {errors.aceptaTerminos.message}
              </p>
            )}
          </div>
        </div>

        {/* Botón de Envío con Estado de Carga (Submitting) */}
        <button
          type="submit"
          disabled={isSubmitting}
          className="w-full py-3 px-4 bg-blue-600 text-white font-semibold rounded-lg hover:bg-blue-700 focus:outline-none focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 disabled:bg-slate-300 disabled:cursor-not-allowed transition-all flex items-center justify-center space-x-2"
        >
          {isSubmitting ? (
            <>
              <svg className="animate-spin h-5 w-5 text-white" viewBox="0 0 24 24" fill="none">
                <circle className="opacity-25" cx="12" cy="12" r="10" stroke="currentColor" strokeWidth="4" />
                <path className="opacity-75" fill="currentColor" d="M4 12a8 8 0 018-8V0C5.373 0 0 5.373 0 12h4z" />
              </svg>
              <span>Procesando...</span>
            </>
          ) : (
            <span>Completar Registro</span>
          )}
        </button>
      </form>
    </div>
  );
}
