    12.2: Enrutamiento SPA con React Router

    1. Principios de Navegación SPA y History API

    En las aplicaciones web tradicionales (Multi-Page Applications - MPA), cada cambio de página implica una nueva petición HTTP al servidor, el cual devuelve un documento HTML completo provocando un refresco total de la pantalla.

    En una Single Page Application (SPA) con React, la navegación se gestiona íntegramente en el cliente. React Router intercepta los cambios de URL utilizando la History API del navegador (window.history.pushState y popstate) para modificar la barra de direcciones sin recargar la página ni perder el estado de la aplicación.

    2. Configuración del Proveedor y Declaración de Rutas

    Para activar el enrutamiento cliente, toda la aplicación (o el árbol de componentes que requiera navegación) debe envolverse en el proveedor <BrowserRouter>.

    import React from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

function Home() { return <h2>Página Principal</h2>; }
function About() { return <h2>Sobre Nosotros</h2>; }
function NotFound() { return <h2>Error 404: Página no encontrada</h2>; }

export function AppRoutes() {
  return (
    <BrowserRouter>
      <Routes>
        <Route element="{<Home" path="/"/>} />
        <Route element="{<About" path="/about"/>} />
        {/* Ruta comodín (Fallback 404) */}
        <Route element="{<NotFound" path="*"/>} />
      </Routes>
    </BrowserRouter>
  );
}

    3. Navegación Declarativa: <Link/> vs <NavLink/>

    Para evitar recargas completas, no se deben utilizar etiquetas HTML <a> convencionales. React Router ofrece componentes equivalentes:

    • <Link to="...">: Renderiza un enlace cliente que actualiza la URL de forma síncrona sin recarga.
    • <NavLink to="...">: Similar a <Link/>, pero permite aplicar estilos o clases CSS dinámicas según si la ruta coincide con la URL actual (isActive).
    import React from 'react';
import { NavLink } from 'react-router-dom';

export function NavigationBar() {
  return (
    <nav>
      <NavLink className="{({" isActive to="/"> (isActive ? 'nav-link active' : 'nav-link')}
      >
        Inicio
      </NavLink>

      <NavLink isActive style="{({" to="/about"> ({
          fontWeight: isActive ? 'bold' : 'normal',
          color: isActive ? '#007bff' : '#333',
        })}
      >
        Nosotros
      </NavLink>
    </nav>
  );
}

    4. Rutas Dinámicas (useParams) y Parámetros de Búsqueda (useSearchParams)

    4.1. Parámetros de Ruta (useParams)

    Las rutas dinámicas permiten definir segmentos de URL variables prefijados por dos puntos (:param). El hook useParams permite extraer dichos valores en los componentes destino.

    import React from 'react';
import { useParams } from 'react';

// Declaración en <Routes>: <Route element="{<DetalleUsuario" path="/usuario/:userId"/>} />

export function DetalleUsuario() {
  const { userId } = useParams<{ userId: string }>();

  return <div>Cargando información del usuario ID: {userId}</div>;
}

    4.2. Query Parameters (useSearchParams)

    Para gestionar filtros, ordenación o paginación en la URL (/productos?categoria=tech&sort=asc), se utiliza el hook useSearchParams, cuyo comportamiento se asemeja a useState.

    import React from 'react';
import { useSearchParams } from 'react';

export function CatalogoProductos() {
  const [searchParams, setSearchParams] = useSearchParams();

  const categoria = searchParams.get('categoria') || 'todas';
  const orden = searchParams.get('sort') || 'asc';

  const aplicarFiltro = (nuevaCategoria: string) => {
    setSearchParams({ categoria: nuevaCategoria, sort: orden });
  };

  return (
    <div>
      <p>Categoría actual: {categoria} | Orden: {orden}</p>
      <button onClick={() => aplicarFiltro('electronica')}>Electrónica</button>
      <button onClick={() => aplicarFiltro('ropa')}>Ropa</button>
    </div>
  );
}

    5. Arquitectura de Rutas Anidadas (Nested Routes) y <Outlet/>

    Las rutas anidadas permiten construir estructuras jerárquicas reutilizando componentes de diseño (layouts) que contienen elementos comunes (cabeceras, barras laterales) mientras sub-vistas cambiantes se renderizan en el marcado interno mediante <Outlet/>.

    import React from 'react';
import { Routes, Route, Outlet, Link } from 'react-router-dom';

// Layout Principal con barra lateral permanente
function DashboardLayout() {
  return (
    <div style={{ display: 'flex' }}>
      <aside style={{ width: '200px', background: '#f4f4f4', padding: '15px' }}>
        <h3>Panel</h3>
        <ul>
          <li><Link to="/dashboard/resumen">Resumen</Link></li>
          <li><Link to="/dashboard/ajustes">Ajustes</Link></li>
        </ul>
      </aside>

      <main style={{ flex: 1, padding: '20px' }}>
        {/* Punto de inyección para las rutas hijas */}
        <Outlet/>
      </main>
    </div>
  );
}

function ResumenDashboard() { return <h2>Visión General de Métricas</h2>; }
function AjustesDashboard() { return <h2>Configuración de Cuenta</h2>; }

export function AppDashboard() {
  return (
    <Routes>
      <Route element="{<DashboardLayout" path="/dashboard"/>}>
        <Route element="{<ResumenDashboard" path="resumen"/>} />
        <Route element="{<AjustesDashboard" path="ajustes"/>} />
      </Route>
    </Routes>
  );
}

    6. Navegación Programática y Rutas Protegidas

    6.1. Redirección Programática (useNavigate)

    El hook useNavigate devuelve una función que permite redirigir al usuario imperativamente tras completar una acción (p. ej., enviar un formulario o iniciar sesión).

    import React from 'react';
import { useNavigate } from 'react';

export function FormularioLogin() {
  const navigate = useNavigate();

  const handleLogin = (e: React.FormEvent) => {
    e.preventDefault();
    // Lógica de autenticación...
    navigate('/dashboard/resumen', { replace: true });
  };

  return (
    <form onSubmit={handleLogin}>
      <button type="submit">Iniciar Sesión</button>
    </form>
  );
}

    6.2. Protección de Rutas Privadas (Guarda de Autenticación)

    Para restringir el acceso a ciertas vistas a usuarios no autenticados, se utiliza un componente contenedor de protección junto con <Navigate/>:

    import React from 'react';
import { Navigate, Outlet } from 'react-router-dom';

interface ProtectedRouteProps {
  estaAutenticado: boolean;
  redirectPath?: string;
}

export function RutaProtegida({
  estaAutenticado,
  redirectPath = '/login'
}: ProtectedRouteProps) {
  if (!estaAutenticado) {
    return <Navigate replace to="{redirectPath}"/>;
  }

  return <Outlet/>;
}
