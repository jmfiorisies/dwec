    UD 10: Manipulación DOM, Virtual DOM, Optimización y Resiliencia UI (RA6) — Visión General

    1. Presentación y Contextualización Curricular

    La Unidad Didáctica 10 aborda la arquitectura del renderizado en React y la interacción estratégica entre el plano declarativo (el Virtual DOM) y la capa imperativa del navegador (el DOM Real), integrando técnicas de optimización y patrones de resiliencia en la interfaz de usuario.

    En el paradigma de React, la interfaz de usuario es una función pura del estado ($UI = f(state)$). Sin embargo, existen escenarios del mundo real (medición de geometrías, gestión del foco, integración con librerías imperativas, animaciones o procesamiento de datos masivos) que requieren acceder de forma segura al DOM nativo sin romper el ciclo de reconciliación.

    Paralelamente, para garantizar aplicaciones estables a 60 FPS y tolerantes a fallos, la unidad se divide en tres ejes fundamentales:

    1. Acceso Seguro al DOM: Uso avanzado del hook useRef para mantener referencias mutables a nodos nativos y valores entre re-renderizados sin desencadenar nuevos ciclos de dibujado, junto con useImperativeHandle y forwardRef.
    2. Ciclo de Reconciliación y Optimización: Comprensión profunda de cómo React Fiber calcula las diferencias (diffing) e influye en el DOM Real mediante ejecuciones por fases (Render y Commit), aplicando React.memo, useCallback y useMemo.
    3. Resiliencia UI y Cargas Asíncronas: Implementación de Error Boundaries para aislar fallos de renderizado y evitar la "pantalla blanca", junto con la carga declarativa de componentes mediante <Suspense/> y React.lazy().

    2. Resultado de Aprendizaje y Criterios de Evaluación (RA6)

    RA6: Optimiza el rendimiento de aplicaciones web en el entorno cliente controlando el ciclo de vida del dibujado, aplicando técnicas de reconciliación del Virtual DOM, gestionando accesos imperativos al DOM de forma segura y garantizando la tolerancia a fallos en la interfaz.

    Desglose Detallado de Criterios de Evaluación (CE):

    • CE6.a: Se ha analizado la arquitectura del Virtual DOM, el algoritmo de reconciliación y las fases de Renderizado y Commit en el motor React Fiber.
    • CE6.b: Se ha utilizado el hook useRef para almacenar referencias mutables persistentes que no desencadenan re-renderizados al actualizarse.
    • CE6.c: Se han implementado accesos directos al DOM nativo para la manipulación del foco, medición de elementos (getBoundingClientRect), reproducción multimedia e integración con Canvas/SVG.
    • CE6.d: Se ha aplicado el patrón de reenvío de referencias mediante forwardRef y la exposición controlada de API imperativas con useImperativeHandle.
    • CE6.e: Se ha evitado la re-ejecución de componentes puros ante cambios de estado no relevantes utilizando React.memo y comparadores personalizados.
    • CE6.f: Se ha estabilizado la igualdad referencial de funciones de callback e instancias complejas mediante useCallback y useMemo.
    • CE6.g: Se han implementado capturadores de errores (Error Boundaries) para aislar fallos de tiempo de ejecución y presentar interfaces de degradación progresiva (fallback UI).
    • CE6.h: Se han gestionado las cargas asíncronas de código y componentes mediante React.lazy y <Suspense/>.

    4. Mapa Estructural de Persistencia y Gestión de Interfaz

    Herramienta Tipo Acceso / Retorno Dispara Re-render Caso de Uso Principal
    useState Hook [value, setValue] SÍ Estado reactivo visual de la interfaz.
    useRef Hook { current: T } NO Almacenar nodos DOM nativos o valores persistentes silentes.
    React.memo HOC Componente optimizado NO Prevenir re-renders de un componente hijo si sus props no cambian.
    useCallback Hook Función memorizada NO Preservar identidad referencial de callbacks pasados como props.
    useMemo Hook Valor calculado NO Evitar el re-cálculo de operaciones computacionalmente costosas ($O(N^2)$).
    Error Boundary Clase / Lib Componente Envolvente N/A Interceptar errores Javascript no capturados en el árbol de renderizado.
    <Suspense/> Core Wrapper Component N/A Mostrar UI de carga (fallback) mientras se resuelven recursos asíncronos.
