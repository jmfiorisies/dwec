    Subunidad 9.1: Eventos Sintéticos y Manejo de Interacciones en React

    1. La Abstracción SyntheticEvent y el Sistema de Eventos de React

    En la arquitectura moderna de desarrollo frontend con React, la interacción del usuario no se gestiona vinculando directamente escuchadores de eventos nativos del navegador (addEventListener) a cada elemento individual del Document Object Model (DOM). En su lugar, React implementa un sistema de eventos sintéticos basado en una capa de abstracción denominada SyntheticEvent.

    1.1. ¿Qué es un SyntheticEvent?

    Un SyntheticEvent es un envoltorio (wrapper) multiplataforma alrededor del evento nativo del navegador. Implementa la misma interfaz que el estándar W3C para eventos del DOM, corrigiendo las discrepancias e inconsistencias de comportamiento entre diferentes motores de ejecución (V8, WebKit, Gecko).

    Ventajas del uso de SyntheticEvent:

    • Consistencia Cross-Browser: Propiedades como e.target, e.currentTarget o e.key se comportan exactamente igual independientemente de la versión o tipo de navegador en el que se ejecute la aplicación.
    • Optimización de Memoria (Delegación de Eventos): En lugar de adjuntar cientos de eventos individuales a elementos de listas o tablas grandes, React registra un único escuchador de eventos en el contenedor raíz de la aplicación (generalmente #root en React 18+). Todos los eventos burbujean (bubbling) hasta la raíz, donde React los procesa y despacha al componente correspondiente.
    • Mantenibilidad Declarativa: La gestión de eventos se integra de forma directa y legible dentro de la sintaxis JSX.

    2. Sintaxis y Registro de Manejadores de Eventos en JSX

    A diferencia de HTML tradicional donde los eventos se escriben en minúsculas y reciben cadenas de texto (onclick="ejecutar()"), en React los eventos siguen la convención camelCase y reciben referencias a funciones.

    2.1. Nombres de Atributos de Eventos Comunes

    Categoría de Evento Atributo JSX Evento Nativo Equivalente
    Ratón onClick, onDoubleClick, onMouseDown, onMouseEnter, onMouseLeave click, dblclick, mousedown, mouseenter, mouseleave
    Teclado onKeyDown, onKeyUp, onKeyPress keydown, keyup, keypress
    Formulario onChange, onSubmit, onInput, onFocus, onBlur change, submit, input, focus, blur
    Portapapeles onCopy, onCut, onPaste copy, cut, paste
    Táctil / Puntero onTouchStart, onTouchMove, onPointerDown, onPointerMove touchstart, touchmove, pointerdown, pointermove

    2.2. Referencia a Función vs. Invocación Inmediata

    Uno de los errores más frecuentes al iniciarse en React es invocar la función manejadora dentro del atributo JSX en lugar de pasar su referencia.

    // ❌ INCORRECTO: Invocación inmediata.
// La función 'handleClick' se ejecuta automáticamente durante el renderizado,
// asignando su valor de retorno al evento, lo que suele provocar bucles infinitos de re-renders.
<button onClick={handleClick()}>Guardar</button>

// ✅ CORRECTO: Paso de la referencia a la función.
// La función 'handleClick' solo se ejecutará cuando el usuario haga clic en el botón.
<button onClick={handleClick}>Guardar</button>

    2.3. Paso de Parámetros a Manejadores de Eventos

    Cuando se necesita transmitir argumentos adicionales a un manejador de eventos (por ejemplo, el identificador único de un elemento dentro de una lista), se debe utilizar una función flecha anónima o una función parcialmente aplicada.

    import React from 'react';

interface Elemento {
  id: number;
  nombre: string;
}

export function ListaElementos() {
  const elementos: Elemento[] = [
    { id: 101, nombre: 'Módulo DWEC' },
    { id: 102, nombre: 'Módulo DIW' },
  ];

  // Manejador que acepta el evento sintético y el ID del elemento
  const handleEliminar = (event: React.MouseEvent<HTMLButtonElement>, id: number) => {
    console.log(`Eliminando elemento con ID: ${id}`);
    console.log(`Coordenada X del clic: ${event.clientX}`);
  };

  return (
    <ul>
      {elementos.map((item) => (
        <li key={item.id}>
          <span>{item.nombre}</span>

          {/* ✅ Opción A: Función flecha explícita que pasa 'event' e 'id' */}
          <button onClick={(e) => handleEliminar(e, item.id)}>
            Eliminar
          </button>
        </li>
      ))}
    </ul>
  );
}

    3.1. Tipos Genéricos de Eventos de Uso Habitual

    Para tipar el objeto de evento, React proporciona tipos genéricos que aceptan el tipo de elemento del DOM (HTMLElement) como parámetro de tipo:

    • React.MouseEvent<HTMLButtonElement>: Clics en botones o divisiones.
    • React.ChangeEvent<HTMLInputElement HTMLSelectElement |>: Captura de cambios en campos de texto, selectores o casillas de verificación.
    • React.FormEvent<HTMLFormElement>: Envíos e interacciones con formularios.
    • React.KeyboardEvent<HTMLInputElement>: Captura de teclas pulsadas (e.key, e.code).
    • React.FocusEvent<HTMLInputElement>: Perfeccionamiento de validaciones al perder o ganar foco (blur / focus).

    3.2. Diferencia Crítica: e.target vs. e.currentTarget

    Al tipar eventos en TypeScript, es fundamental comprender la diferencia semántica entre ambas propiedades:

    const handleContenedorClick = (event: React.MouseEvent<HTMLDivElement>) => {
  // e.target: El elemento EXACTO en el que se hizo clic físico (ej. el <button> o el <span> interno)
  console.log('Elemento origen:', event.target);

  // e.currentTarget: El elemento HTML al que está ASOCIADO este manejador de eventos (la <div className="card">)
  console.log('Elemento que escucha:', event.currentTarget);
};

return (
  <div className="card" onClick={handleContenedorClick}>
    <h3>Título de la Tarjeta</h3>
    <button>Acción Interna</button>
  </div>
);

    4. Control del Flujo: Prevención de Comportamientos por Defecto y Propagación

    El objeto SyntheticEvent expone métodos para controlar la ejecución predeterminada del navegador y la fase de burbujeo (Event Bubbling).

    4.1. e.preventDefault()

    Detiene la acción nativa que el navegador realizaría por defecto ante una interacción:

    • Previene el envío HTTP síncrono y la recarga total de página en envíos de formularios (<form>).
    • Cancela la navegación predeterminada en hipervínculos (<a href="...">).
    • Evita el comportamiento predeterminado al soltar archivos en zonas de Drag and Drop.
    const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
  // Previene que el navegador recargue la página web al enviar el formulario
  e.preventDefault(); 
  console.log('Procesando datos del formulario mediante JavaScript...');
};

    4.2. e.stopPropagation()

    Detiene la propagación del evento hacia arriba en la jerarquía del árbol DOM (Event Bubbling), impidiendo que los componentes padres capturen la misma interacción.

    export function TarjetaInteractiva() {
  const handlePadreClick = () => {
    console.log('Clic capturado en el contenedor Padre');
  };

  const handleBotonHijoClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    // Detiene el burbujeo para que NO se active 'handlePadreClick'
    e.stopPropagation(); 
    console.log('Clic procesado únicamente en el Botón Hijo');
  };

  return (
    <div className="card-container" onClick={handlePadreClick}>
      <h2>Título de Tarjeta</h2>
      <button onClick={handleBotonHijoClick}>
        Botón con Propagación Detenida
      </button>
    </div>
  );
}

    5. Paso de Manejadores de Eventos mediante Props (Comunicación Hijo a Padre)

    En el modelo de datos unidireccional de React, un componente hijo no debe modificar directamente el estado global ni el de sus padres. Para comunicar una interacción iniciada en un hijo hacia el ancestro, el padre transmite una función de retorno (callback) mediante props.

    Convención de Nomenclatura Estándar:

    • En las Props del Hijo: Se utiliza el prefijo on seguido del evento (onEliminar, onSeleccionar, onCambiarEstado).
    • En el Manejador Interno del Padre: Se utiliza el prefijo handle (handleEliminar, handleSeleccionar).
    sequenceDiagram
    autonumber
    actor User as Usuario
    participant Hijo as Componente Hijo (<BotonBorrar />)
    participant Padre as Componente Padre (<ListaUsuarios />)

    Padre->>Hijo: Transmite el callback mediante prop: onBorrar={handleBorrarUsuario}
    User->>Hijo: Realiza un Clic en el botón
    Hijo->>Hijo: Ejecuta onClick interno y procesa e.stopPropagation()
    Hijo->>Padre: Invoca la función recibida por props: props.onBorrar(id)
    Padre->>Padre: Actualiza su estado local o ejecuta lógica de negocio

    import React from 'react';

// 1. Interfaz de Props del Componente Hijo
interface BotonAccionProps {
  label: string;
  idItem: number;
  onEjecutarAccion: (id: number) => void; // Callback tipado
}

// 2. Componente Hijo
export const BotonAccion: React.FC<BotonAccionProps> = ({
  label,
  idItem,
  onEjecutarAccion,
}) => {
  return (
    <button 
      className="btn-action" 
      onClick={() => onEjecutarAccion(idItem)}
    >
      {label}
    </button>
  );
};

// 3. Componente Padre
export function ContenedorPrincipal() {
  const handleProcesarItem = (id: number) => {
    console.log(`Padre notificado: El usuario seleccionó el ítem ${id}`);
  };

  return (
    <div className="wrapper">
      <BotonAccion 
        label="Procesar Registro #45" 
        idItem={45} 
        onEjecutarAccion={handleProcesarItem} 
      />
    </div>
  );
}

    6. Demostración Práctica Completa: Panel de Control Interactivo

    A continuación se presenta un caso práctico integral en TypeScript que combina captura de eventos de teclado, ratón, formularios, control de propagación y callbacks entre componentes:

    import React, { useState } from 'react';

// Definición del tipo para los ítems de la lista
interface Tarea {
  id: number;
  texto: string;
}

// --- COMPONENTE HIJO: Elemento de la lista con acciones ---
interface FilaTareaProps {
  tarea: Tarea;
  onEliminarTarea: (id: number) => void;
}

export const FilaTarea: React.FC<FilaTareaProps> = ({ tarea, onEliminarTarea }) => {
  const handleFilaClick = () => {
    console.log(`Se ha seleccionado la fila de la tarea: "${tarea.texto}"`);
  };

  const handleBotonEliminar = (e: React.MouseEvent<HTMLButtonElement>) => {
    // Evitamos que el clic en el botón active el evento 'onClick' de la fila contenedora
    e.stopPropagation();
    onEliminarTarea(tarea.id);
  };

  return (
    <li 
      onClick={handleFilaClick} 
      className="tarea-item" 
      style={{ cursor: 'pointer', padding: '8px', borderBottom: '1px solid #ccc' }}
    >
      <span>{tarea.texto}</span>
      <button onClick={handleBotonEliminar} style={{ marginLeft: '12px' }}>
        Eliminar
      </button>
    </li>
  );
};

// --- COMPONENTE PADRE: Gestor principal de tareas ---
export function GestorTareasAvanzado() {
  const [tareas, setTareas] = useState<Tarea[]>([
    { id: 1, texto: 'Estudiar SyntheticEvents en React' },
    { id: 2, texto: 'Implementar callbacks de comunicación' },
  ]);
  const [nuevoTexto, setNuevoTexto] = useState<string>('');

  // Manejador del cambio de texto con tipado estricto
  const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setNuevoTexto(e.target.value);
  };

  // Manejador del teclado para detectar la tecla 'Escape'
  const handleKeyDownInput = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Escape') {
      setNuevoTexto(''); // Limpia el campo al pulsar Escape
    }
  };

  // Manejador del envío del formulario
  const handleFormSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault(); // Previene recarga de la página

    if (nuevoTexto.trim() === '') return;

    const nuevaTarea: Tarea = {
      id: Date.now(),
      texto: nuevoTexto.trim(),
    };

    setTareas([...tareas, nuevaTarea]);
    setNuevoTexto(''); // Resetea el input
  };

  // Callback para eliminar una tarea recibido desde el hijo
  const handleEliminarTarea = (idTarea: number) => {
    setTareas(tareas.filter((t) => t.id !== idTarea));
  };

  return (
    <div className="panel-gestor" style={{ maxWidth: '450px', margin: '20px auto' }}>
      <h2>Gestor de Tareas Interactivo</h2>

      <form onSubmit={handleFormSubmit} style={{ marginBottom: '16px' }}>
        <input
          type="text"
          value={nuevoTexto}
          onChange={handleInputChange}
          onKeyDown={handleKeyDownInput}
          placeholder="Escribe una tarea (Esc para cancelar)..."
          style={{ width: '70%', padding: '6px' }}
        />
        <button type="submit" style={{ padding: '6px 12px', marginLeft: '8px' }}>
          Añadir
        </button>
      </form>

      <ul style={{ listStyle: 'none', padding: 0 }}>
        {tareas.map((item) => (
          <FilaTarea
            key={item.id}
            tarea={item}
            onEliminarTarea={handleEliminarTarea}
          />
        ))}
      </ul>
    </div>
  );
}
