    UD 4: Objetos y Programación Orientada a Objetos (RA3)

    Referencia Módulo DWEC: Resultado de Aprendizaje 3 (RA3) — Desarrolla aplicaciones web utilizando el modelo de objetos de JavaScript, integrando estructuras clave-valor, la cadena de prototipos nativa, clases ES6+, herencia y mecanismos modernos de encapsulamiento.

    1. Objetos Literales y Estructura Clave-Valor 🔑

    En JavaScript, casi todo es un objeto o se comporta como tal. Un Objeto es una colección dinámica de propiedades, donde cada propiedad está formada por un par clave-valor (key-value). Las claves son cadenas de texto o Symbol, y los valores pueden ser primitivos, arrays, otros objetos o funciones (métodos).

    // Creación de objeto literal con sintaxis moderna
const usuario = {
  id: 101,
  nombre: "Ana Gómez",
  email: "ana@ejemplo.com",
  "rol-usuario": "Administrador", // Clave con guion requiere comillas
  activo: true,

  // Método condensado (ES6)
  obtenerPerfil() {
    return `${this.nombre} (${this["rol-usuario"]})`;
  }
};

    Acceso y Manipulación de Propiedades

    Existen dos formas de acceder a las propiedades de un objeto:

    1. Notación por punto (.): Es la sintaxis preferida por su legibilidad, pero requiere que la clave sea un identificador válido.
    2. Notación por corchetes ([]): Indispensable cuando la clave está almacenada en una variable, contiene caracteres especiales (guiones, espacios) o se calcula dinámicamente.
    // Acceso por punto
console.log(usuario.nombre); // "Ana Gómez"

// Acceso por corchetes
const propiedadDinamica = "email";
console.log(usuario[propiedadDinamica]); // "ana@ejemplo.com"
console.log(usuario["rol-usuario"]);     // "Administrador"

// Añadir, modificar y eliminar propiedades
usuario.telefono = "+34 600000000"; // Añade propiedad
usuario.activo = false;             // Modifica propiedad
delete usuario.email;               // Elimina propiedad

    Operaciones Avanzadas: Desestructuración y Spread

    ES6 introdujo mecanismos para extraer valores y clonar objetos de forma inmutable.

    const producto = {
  id: "P01",
  nombre: "Teclado Mecánico",
  precio: 85,
  categoria: "Periféricos"
};

// Desestructuración con valores por defecto y alias
const { nombre, precio: precioEUR, enStock = true } = producto;
console.log(nombre, precioEUR, enStock); // "Teclado Mecánico", 85, true

// Operador Spread (...) para clonación superficial (Shallow Copy) y fusión
const detallesEnvio = { pesoKg: 1.2, dimensiones: "40x15cm" };

const productoCompleto = {
  ...producto,
  ...detallesEnvio,
  precio: 90 // Sobrescribe el precio anterior
};

    Métodos Estáticos de Object

    El objeto global Object proporciona utilidades para inspeccionar y manipular objetos:

    const configuracion = { servidor: "localhost", puerto: 3000, ssl: true };

// Inspección de claves, valores y entradas
console.log(Object.keys(configuracion));   // ["servidor", "puerto", "ssl"]
console.log(Object.values(configuracion)); // ["localhost", 3000, true]
console.log(Object.entries(configuracion)); 
// [["servidor", "localhost"], ["puerto", 3000], ["ssl", true]]

// Control de Mutabilidad
const constantes = { PI: 3.14159, GRAVEDAD: 9.8 };

Object.freeze(constantes); // Impide añadir, borrar o modificar propiedades
// constantes.PI = 3;      // Error en strict mode / Ignorado en modo normal

const sesion = { usuario: "Carlos" };
Object.seal(sesion);       // Permite modificar valores existentes, pero IMPIDE añadir/borrar
sesion.usuario = "Carlos A."; // VÁLIDO
delete sesion.usuario;        // INVALIDO

    2. El Modelo de Prototipos de JavaScript 🧬

    A diferencia de lenguajes orientados a objetos tradicionales como Java o C++, JavaScript implementa herencia basada en prototipos (Prototypal Inheritance). Cada objeto tiene una referencia interna hacia otro objeto llamado su prototipo ([[Prototype]]).

    La Cadena de Prototipos (Prototype Chain)

    Cuando se intenta acceder a una propiedad o método de un objeto:

    1. El motor busca la propiedad en el propio objeto (propiedad propia).
    2. Si no la encuentra, busca en el prototipo asignado a ese objeto.
    3. El proceso se repite ascendiendo por la cadena de prototipos hasta llegar a Object.prototype.
    4. Si alcanza el final de la cadena (null) sin encontrarla, retorna undefined.
    flowchart TD
    SubObjeto["Objeto Instancia (ej: miArray)"] -->|__proto__| ProtoPadre["Array.prototype"]
    ProtoPadre -->|__proto__| ProtoBase["Object.prototype"]
    ProtoBase -->|__proto__| ProtoNull["null"]

    SubObjeto -. "Tiene push(), map()?" .-> ProtoPadre
    ProtoPadre -. "Tiene toString(), valueOf()?" .-> ProtoBase

    Herencia Basada en Prototipos (Mecanismo Tradicional)

    Antes de ES6, la herencia se configuraba asociando objetos manualmente mediante Object.create() o modificando la propiedad prototype de las funciones constructoras.

    // Función Constructora (Convención: Primera letra en mayúscula)
function Persona(nombre, edad) {
  this.nombre = nombre;
  this.edad = edad;
}

// Métodos compartidos adjuntos al prototipo (Ahorra memoria)
Persona.prototype.saludar = function() {
  return `Hola, soy ${this.nombre} y tengo ${this.edad} años.`;
};

const persona1 = new Persona("David", 30);
console.log(persona1.saludar()); // "Hola, soy David y tengo 30 años."

// Verificación de propiedades
console.log(persona1.hasOwnProperty("nombre"));  // true (propiedad propia)
console.log(persona1.hasOwnProperty("saludar")); // false (propiedad del prototipo)

    3. Clases en ES6+: Sintaxis y Métodos 🏛️

    La palabra clave class introducida en ES6 es una azúcar sintáctica (Syntactic Sugar) sobre el modelo de prototipos subyacente. No añade un nuevo paradigma de objetos a JavaScript, pero proporciona una sintaxis más limpia, legible y similar a otros lenguajes.

    Estructura de una Clase

    class Vehiculo {
  // Constructor: Método especial que se ejecuta al instanciar con 'new'
  constructor(marca, modelo, precio) {
    this.marca = marca;
    this.modelo = modelo;
    this.precio = precio;
  }

  // Método de Instancia (se asigna automáticamente al prototipo de la clase)
  obtenerDetalles() {
    return `${this.marca} ${this.modelo} - $${this.precio}`;
  }

  // Getters y Setters: Interceptan el acceso y modificación de propiedades
  get descripcion() {
    return `${this.marca.toUpperCase()} - ${this.modelo}`;
  }

  set actualizarPrecio(nuevoPrecio) {
    if (nuevoPrecio <= 0) {
      throw new Error("El precio debe ser un valor positivo.");
    }
    this.precio = nuevoPrecio;
  }

  // Método Estático: Se invoca sobre la Clase, NO sobre las instancias
  static esVehiculoValido(objeto) {
    return objeto instanceof Vehiculo;
  }
}

// Instanciación
const miCoche = new Vehiculo("Toyota", "Corolla", 22000);
console.log(miCoche.obtenerDetalles()); // "Toyota Corolla - $22000"
console.log(miCoche.descripcion);      // "TOYOTA - Corolla" (Uso del Getter)

miCoche.actualizarPrecio = 21000;       // Uso del Setter
console.log(Vehiculo.esVehiculoValido(miCoche)); // true (Invocación estática)

    4. Herencia y Polimorfismo con extends y super 🌳

    La herencia permite crear clases derivadas que heredan y extienden el comportamiento de una clase base.

    classDiagram
    class Empleado {
        +String nombre
        +Number salario
        +obtenerFicha() String
    }
    class Desarrollador {
        +String lenguajePrincipal
        +obtenerFicha() String
    }
    Empleado <|-- Desarrollador : Extiende

    Extensión de Clases y Sobrescritura de Métodos

    • extends: Establece el enlace jerárquico de prototipos entre clases.
    • super(): En el constructor derivado, ejecuta el constructor de la clase base. Debe invocarse antes de usar this.
    • Polimorfismo: La clase derivada puede reimplementar un método heredado (sobrescritura) para adaptar su comportamiento.
    // Clase Base
class Empleado {
  constructor(nombre, salario) {
    this.nombre = nombre;
    this.salario = salario;
  }

  obtenerFicha() {
    return `Empleado: ${this.nombre} | Salario: $${this.salario}`;
  }
}

// Clase Derivada
class Desarrollador extends Empleado {
  constructor(nombre, salario, lenguajePrincipal) {
    // Llamada obligatoria al constructor de la clase base
    super(nombre, salario); 
    this.lenguajePrincipal = lenguajePrincipal;
  }

  // Sobrescritura de Método (Polimorfismo)
  obtenerFicha() {
    // Reutiliza la lógica del método heredado con super.metodo()
    const fichaBase = super.obtenerFicha();
    return `${fichaBase} | Lenguaje: ${this.lenguajePrincipal}`;
  }

  programar() {
    return `${this.nombre} está escribiendo código en ${this.lenguajePrincipal}...`;
  }
}

const dev = new Desarrollador("Lucía", 45000, "JavaScript");
console.log(dev.obtenerFicha()); // "Empleado: Lucía | Salario: $45000 | Lenguaje: JavaScript"
console.log(dev.programar());    // "Lucía está escribiendo código en JavaScript..."

    5. Encapsulamiento y Campos Privados (ES2022) 🔒

    Históricamente, JavaScript no tenía soporte nativo para visibilidad de propiedades (privadas/públicas). Los desarrolladores utilizaban la convención de prefijar con guion bajo _ (_propiedad) para indicar privacidad sintáctica, aunque la propiedad seguía siendo accesible públicamente.

    Desde ES2022, JavaScript incluye campos privados reales indicados mediante el prefijo #.

    Propiedades, Métodos y Accesores Privados #

    Cualquier propiedad o método declarado con # es completamente inaccesible e invisible fuera del cuerpo de la propia clase. Intentar acceder directamente provoca un error de sintaxis (SyntaxError).

    class CuentaBancaria {
  // Declara campos privados (ES2022)
  #saldo = 0;
  #pin;

  constructor(titular, pinInicial, depositoInicial) {
    this.titular = titular; // Propiedad pública
    this.#pin = pinInicial;
    this.#saldo = depositoInicial;
  }

  // Método público que interactúa con el estado privado de forma segura
  ingresar(monto, pinIngresado) {
    if (!this.#validarPin(pinIngresado)) {
      return "PIN Incorrecto. Operación cancelada.";
    }
    if (monto <= 0) return "Monto inválido.";

    this.#saldo += monto;
    this.#registrarTransaccion("Ingreso", monto);
    return `Ingreso exitoso. Nuevo saldo: $${this.#saldo}`;
  }

  // Método Privado (Inaccessible desde fuera)
  #validarPin(pin) {
    return this.#pin === pin;
  }

  #registrarTransaccion(tipo, monto) {
    console.log(`LOG: Transacción [${tipo}] por $${monto} registrada.`);
  }

  // Getter explícito para lectura controlada
  obtenerSaldo(pinIngresado) {
    return this.#validarPin(pinIngresado) 
      ? `Saldo actual: $${this.#saldo}` 
      : "Acceso denegado.";
  }
}

const miCuenta = new CuentaBancaria("Marcos", 1234, 500);

console.log(miCuenta.titular); // "Marcos"
console.log(miCuenta.ingresar(200, 1234)); // "Ingreso exitoso. Nuevo saldo: $700"

// Intentos de acceso ilegal:
// console.log(miCuenta.#saldo);         // SyntaxError: Private field '#saldo' must be declared in an enclosing class
// miCuenta.#validarPin(1234);           // SyntaxError: Private field '#validarPin' must be declared in an enclosing class

    6. Comparativa de Paradigma y Métodos de Creación 📊

    Criterio Objetos Literales Funciones Constructoras Clases ES6+ (class)
    Caso de Uso Principal Estructuras sencillas de datos clave-valor. Código legado previa estandarización ES6. Desarrollo moderno de OOP, entidades con lógica.
    Instanciación Múltiple Manual (requiere duplicar código o funciones factoría). Mediante operador new. Mediante operador new.
    Herencia Vía Object.setPrototypeOf() o Object.create(). Vía manipulaciones en Prototype. Nativa con sintaxis limpia extends y super.
    Encapsulamiento Mediante Closures en funciones factoría. Mediante Closures locales. Nativo con campos y métodos privados #.
    Rendimiento Memoria $O(n)$ si duplica métodos por cada objeto. $O(1)$ adjuntando métodos a .prototype. $O(1)$ asignando métodos al prototipo implícito.
