    11.2: Optimización de Rendimiento (useMemo, useCallback, React.memo) y Arquitectura Fiber

    1. El Ciclo de Re-renderizado en React y la Arquitectura Fiber

    En React, cuando un componente actualiza su estado local mediante useState, React re-renderiza recursivamente dicho componente y a toda su descendencia en el árbol de Virtual DOM.

    flowchart TD
    subgraph Trigger ["1. Desencadenante (Trigger)"]
        StateChange["Cambio de Estado (setState)"]
    end

    subgraph RenderPhase ["2. Fase de Renderizado (Asíncrona y Pura)"]
        direction TB
        ExecComp["Ejecuta la función del componente"]
        VDOM_New["Genera el nuevo árbol de Virtual DOM"]
        Reconciliation["Algoritmo Diffing de Fiber (Compara VDOM Anterior vs Nuevo)"]
        ExecComp --> VDOM_New --> Reconciliation
    end

    subgraph CommitPhase ["3. Fase de Commit (Síncrona)"]
        direction TB
        DOM_Mutate["Aplica mutaciones mínimas al DOM Real"]
        Effects["Ejecuta useEffect / useLayoutEffect"]
        DOM_Mutate --> Effects
    end

    StateChange ==> ExecComp
    Reconciliation ==> DOM_Mutate

    1.1. Fases de React Fiber

    1. Fase de Render (Render Phase): React procesa el árbol de componentes calculando la nueva estructura del Virtual DOM. Es pura, asíncrona y no realiza mutaciones visibles.
    2. Fase de Commit (Commit Phase): React aplica de forma síncrona las diferencias estrictamente necesarias al DOM Real y ejecuta los efectos secundarios (useEffect).

    2. Memorización de Componentes Puros con React.memo

    React.memo es un Componente de Orden Superior (HOC) que envuelve a un componente funcional para evitar su re-ejecución si sus props no han cambiado (Shallow Comparison).

    flowchart TD
    PadreRender["Padre se Re-renderiza"] --> CheckMemo{"¿El Hijo está envuelto en React.memo?"}

    CheckMemo -->|No| ChildRender["Se re-renderiza el Hijo (Por Defecto)"]
    CheckMemo -->|Sí| PropsCheck{"¿Han cambiado las props? (Shallow Comparison)"}

    PropsCheck -->|Sí| ChildRender
    PropsCheck -->|No| SkipRender["Se OMITE el re-renderizado del Hijo (Ahorro CPU)"]

    3. Estabilización de Referencias con useCallback y useMemo

    3.1. useCallback

    Memoriza la instancia de una función entre re-renderizados:

    $$\text{useCallback(fn, deps)} \equiv \text{useMemo(() => fn, deps)}$$

    3.2. useMemo

    Ejecuta una función de cálculo y almacena en caché su resultado:

    const datosFiltrados = useMemo(() => {
  return datosMasivos.filter((item) => item.nombre.includes(busqueda));
}, [datosMasivos, busqueda]);

    4. Cuadro Comparativo de Hooks de Optimización

    Herramienta Firma ¿Qué Memoriza? Propósito Principal
    React.memo React.memo(Comp, compFn?) Renderizado del Componente JSX Evitar re-renders de hijos si las props son idénticas.
    useCallback useCallback(fn, [deps]) Instancia de la función Preservar la igualdad referencial de funciones pasadas como props.
    useMemo useMemo(() => valor, [deps]) Resultado de un cálculo Evitar re-cálculos pesados ($O(N^2)$) y preservar referencias de objetos/arrays.

    5. Demostración Práctica Completa: DataGrid Optimizado con 1,000 Registros

    import React, { useState, useMemo, useCallback } from 'react';

export interface FilaData {
  id: number;
  usuario: string;
  puntuacion: number;
  categoria: string;
}

interface FilaTablaProps {
  fila: FilaData;
  seleccionada: boolean;
  onToggleSeleccion: (id: number) => void;
}

const FilaTabla = React.memo(function FilaTabla({
  fila,
  seleccionada,
  onToggleSeleccion,
}: FilaTablaProps) {
  return (
    <tr
      onClick={() => onToggleSeleccion(fila.id)}
      className={`border-b transition-colors cursor-pointer ${
        seleccionada ? 'bg-blue-50' : 'hover:bg-slate-50'
      }`}
    >
      <td className="p-3">
        <input type="checkbox" checked={seleccionada} onChange={() => {}} />
      </td>
      <td className="p-3 font-mono text-xs text-slate-500">{fila.id}</td>
      <td className="p-3 font-medium text-slate-800">{fila.usuario}</td>
      <td className="p-3 text-slate-600">{fila.puntuacion} pts</td>
      <td className="p-3">
        <span className="px-2 py-1 text-xs rounded-full bg-slate-100 font-semibold text-slate-700">
          {fila.categoria}
        </span>
      </td>
    </tr>
  );
});

export function DataGridOptimizado() {
  const datosIniciales: FilaData[] = useMemo(() => {
    return Array.from({ length: 1000 }, (_, i) => ({
      id: i + 1,
      usuario: `Usuario_${i + 1}`,
      puntuacion: Math.floor(Math.random() * 1000),
      categoria: i % 2 === 0 ? 'Premium' : 'Estándar',
    }));
  }, []);

  const [filtroTexto, setFiltroTexto] = useState('');
  const [idsSeleccionados, setIdsSeleccionados] = useState<Set<number>>(new Set());

  const datosFiltrados = useMemo(() => {
    return datosIniciales.filter((f) =>
      f.usuario.toLowerCase().includes(filtroTexto.toLowerCase())
    );
  }, [datosIniciales, filtroTexto]);

  const handleToggleSeleccion = useCallback((id: number) => {
    setIdsSeleccionados((prevSet) => {
      const nuevoSet = new Set(prevSet);
      if (nuevoSet.has(id)) {
        nuevoSet.delete(id);
      } else {
        nuevoSet.add(id);
      }
      return nuevoSet;
    });
  }, []);

  return (
    <div className="max-w-4xl mx-auto my-8 p-6 bg-white border border-slate-200 rounded-xl shadow-lg">
      <h2 className="text-xl font-bold mb-4 text-slate-900">DataGrid Optimizado (1,000 Filas)</h2>

      <input
        type="text"
        placeholder="Buscar usuario..."
        value={filtroTexto}
        onChange={(e) => setFiltroTexto(e.target.value)}
        className="w-full mb-4 px-4 py-2 border rounded-lg focus:ring-2 focus:ring-blue-500 focus:outline-none"
      />

      <div className="max-h-96 overflow-y-auto border rounded-lg">
        <table className="w-full text-left border-collapse">
          <thead className="bg-slate-100 sticky top-0 border-b">
            <tr>
              <th className="p-3">Sel.</th>
              <th className="p-3">ID</th>
              <th className="p-3">Usuario</th>
              <th className="p-3">Puntuación</th>
              <th className="p-3">Categoría</th>
            </tr>
          </thead>
          <tbody>
            {datosFiltrados.map((fila) => (
              <FilaTabla fila="{fila}" key="{fila.id}" onToggleSeleccion="{handleToggleSeleccion}" seleccionada="{idsSeleccionados.has(fila.id)}"/>
            ))}
          </tbody>
        </table>
      </div>
    </div>
  );
}
