    11.3: Resiliencia UI con Error Boundaries y Cargas Asíncronas con <Suspense/>

    1. Resiliencia y Captura de Errores con Error Boundaries

    En aplicaciones web complejas, un fallo no capturado en un componente durante la fase de renderizado puede provocar el desmontaje completo del árbol de React, resultando en una pantalla blanca no deseada (White Screen of Death).

    Un Error Boundary es un componente especializado que intercepta errores de JavaScript producidos en el árbol de componentes hijos durante las fases de renderizado, métodos del ciclo de vida y constructores.

    flowchart TD
    subgraph Tree ["Árbol de Componentes React"]
        Root["App Component"] --> EB["Error Boundary Wrapper"]
        EB --> ComponentA["Componente Normal"]
        EB --> ComponentB["Componente con Error de Renderizado ❌"]
    end

    ComponentB -- "Lanza Excepción en Render" --> EB
    EB -- "getDerivedStateFromError" --> Fallback["Renderiza UI de Degradación Progresiva (Fallback UI)"]

    1.1. Métodos Clave de un Error Boundary

    Para que un componente actúe como Error Boundary, debe ser un componente de clase e implementar uno o ambos métodos:

    • static getDerivedStateFromError(error): Método estático que actualiza el estado local para renderizar la UI alternativa (fallback) en el siguiente ciclo.
    • componentDidCatch(error, errorInfo): Método del ciclo de vida utilizado para registrar el error en servicios de telemetría o monitorización (Sentry, LogRocket, Datadog).
    import React, { Component, ErrorInfo, ReactNode } from 'react';

interface Props {
  children: ReactNode;
  fallback?: ReactNode;
}

interface State {
  hasError: boolean;
  error: Error | null;
}

export class ErrorBoundaryClass extends Component<Props, State> {
  public state: State = {
    hasError: false,
    error: null,
  };

  public static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  public componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    console.error('Error no capturado en componente hijo:', error, errorInfo);
  }

  public render() {
    if (this.state.hasError) {
      if (this.props.fallback) {
        return this.props.fallback;
      }
      return (
        <div role="alert" className="p-6 bg-red-50 border border-red-200 rounded-xl my-4">
          <h2 className="text-lg font-bold text-red-800">Ocurrió un error inesperado en este módulo</h2>
          <p className="text-sm text-red-600 mt-1 font-mono">{this.state.error?.message}</p>
          <button
            onClick={() => this.setState({ hasError: false, error: null })}
            className="mt-4 px-4 py-2 bg-red-600 text-white font-medium rounded-lg hover:bg-red-700 transition"
          >
            Reintentar
          </button>
        </div>
      );
    }

    return this.props.children;
  }
}

    2. Cargas Asíncronas Declarativas con <Suspense/> y React.lazy()

    El fraccionamiento de código (Code Splitting) permite dividir el paquete JavaScript de la aplicación en chunks más pequeños que se descargan bajo demanda. React.lazy() permite importar componentes dinámicamente, mientras que <Suspense/> gestiona la interfaz visual de carga mientras el recurso asíncrono se resuelve.

    sequenceDiagram
    autonumber
    actor User as Usuario
    participant React as React (Suspense)
    participant LazyComp as React.lazy Dynamic Import
    participant Server as Servidor / CDN

    User->>React: Navega / Renderiza componente asíncrono
    React->>LazyComp: Solicita import('./WidgetAnalitica')
    React-->>User: Muestra inmediatamente el Fallback UI (Spinner / Skeleton)
    LazyComp->>Server: Descarga chunk .js bajo demanda
    Server-->>LazyComp: Retorna módulo JavaScript
    LazyComp-->>React: Módulo resuelto exitosamente
    React-->>User: Reemplaza Fallback con el Componente Real

    3. Demostración Práctica Completa: Dashboard Resiliente e Integración Completa

    import React, { useState, Suspense, lazy } from 'react';
import { ErrorBoundaryClass } from './ErrorBoundaryClass';

// Carga perezosa (Code-Splitting) del widget analítico
const WidgetAnaliticoComplejo = lazy(() =>
  new Promise<{ default: React.ComponentType<{ forzarError: boolean }> }>((resolve) => {
    setTimeout(() => {
      resolve({
        default: ({ forzarError }) => {
          if (forzarError) {
            throw new Error('Fallo crítico de conexión con la base de datos analítica.');
          }
          return (
            <div className="p-6 bg-emerald-50 border border-emerald-200 rounded-xl">
              <h3 className="text-lg font-bold text-emerald-900">Métricas de Rendimiento en Tiempo Real</h3>
              <p className="text-sm text-emerald-700 mt-2">
                Procesando 1,450 peticiones/segundo con latencia media de 12ms.
              </p>
            </div>
          );
        },
      });
    }, 2000);
  })
);

export function DashboardResiliente() {
  const [simularFallo, setSimularFallo] = useState<boolean>(false);

  return (
    <div className="max-w-3xl mx-auto my-10 p-8 bg-white border border-slate-200 rounded-2xl shadow-xl space-y-6">
      <header className="border-b pb-4">
        <h1 className="text-2xl font-bold text-slate-900">Panel de Control Resiliente</h1>
        <p className="text-sm text-slate-500">Demostración de Error Boundaries y Suspense.</p>
      </header>

      {/* Control de pruebas */}
      <div className="flex items-center space-x-3 p-4 bg-slate-50 rounded-xl border">
        <input
          id="toggleFallo"
          type="checkbox"
          checked={simularFallo}
          onChange={(e) => setSimularFallo(e.target.checked)}
          className="h-4 w-4 text-blue-600 rounded border-slate-300 focus:ring-blue-500"
        />
        <label htmlFor="toggleFallo" className="text-sm font-medium text-slate-700">
          Simular error de renderizado en el módulo analítico
        </label>
      </div>

      {/* Aislamiento con Error Boundary y Carga con Suspense */}
      <ErrorBoundaryClass>
        <Suspense <div className="p-6 bg-slate-50 border border-slate-200 rounded-xl animate-pulse space-y-3" fallback="{">
              <div className="h-4 bg-slate-300 rounded w-1/3"></div>
              <div className="h-3 bg-slate-200 rounded w-2/3"></div>
              <span className="text-xs text-slate-400 font-medium">Cargando módulo dinámico...</span>
            </div>
          }
        >
          <WidgetAnaliticoComplejo forzarError="{simularFallo}"/>
        </Suspense>
      </ErrorBoundaryClass>
    </div>
  );
}
