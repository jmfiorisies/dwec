    11.1: Acceso al DOM Directo, useRef, forwardRef y useImperativeHandle

    1. Anatomía y Naturaleza Interna del Hook useRef

    En React, el flujo de datos predeterminado es top-down (props), y las actualizaciones de interfaz se logran mediante cambios de estado (useState). Cuando se requiere conservar datos que no afecten directamente a la representación visual o interaccionar de forma imperativa con el DOM, se utiliza el hook useRef.

    subgraph useStateMechanism ["Mecanismo de useState"]
        direction TB
        StateVal["Estado React (valor)"] --> StateChange["setEstado(nuevo)"]
        StateChange --> ReRenderTrigger["Re-renderiza el Componente"]
    end

    subgraph useRefMechanism ["Mecanismo de useRef"]

    end

    1.1. Objeto RefObject vs MutableRefObject en TypeScript

    El hook useRef devuelve un objeto contenedor de JavaScript con una propiedad mutable .current. La firma del tipo en TypeScript depende de los genéricos y del valor inicial:

    import { useRef, RefObject, MutableRefObject } from 'react';

// 1. RefObject<T> (Solo lectura sobre el nodo DOM nativo)
const inputRef: RefObject<HTMLInputElement> = useRef<HTMLInputElement>(null);
// inputRef.current es gestionado exclusivamente por React.

// 2. MutableRefObject<T> (Lectura/Escritura para persistencia de valores arbitrarios)
const timerIdRef: MutableRefObject<number | null> = useRef<number | null>(null);
// Se puede mutar directamente: timerIdRef.current = window.setInterval(...);

    1.2. Cuadro Comparativo: useState vs useRef vs Variables Locales

    Propiedad useState useRef Variable Local (let / const)
    Persistencia entre Renders Sí Sí No (Se reinicializa en cada render)
    Desencadena Re-render Sí No (Mutación síncrona y silente) No
    Acceso / Mutación Asíncrono (setEstado()) Síncrono (ref.current = v) Síncrono (asignación)
    Caso de Uso Principal Datos que dictan la UI Nodos DOM, IDs de timers, valores previos Cálculos temporales en el render

    2. Captura y Manipulación de Nodos Nativos del DOM

    Para acceder al nodo DOM de un elemento JSX, se asigna la referencia a la propiedad especial ref.

    2.1. Ciclo de Vida de la Referencia

    Durante la Fase de Render, ref.current contiene el valor inicial (null). En la Fase de Commit (tras actualizar el DOM Real), .current pasa a apuntar al elemento HTML. Por tanto, solo debe accederse a ref.current en manejadores de eventos o dentro de useEffect.

    sequenceDiagram
    autonumber
    participant Comp as Componente (Cuerpo)
    participant VDOM as Virtual DOM (Render Phase)
    participant DOM as DOM Real (Commit Phase)
    participant Effect as useEffect Hook

    Comp->>VDOM: useRef(null) -> ref.current es NULL
    Note over Comp: Prohibido leer/escribir ref.current en el cuerpo del render
    VDOM->>DOM: React monta el nodo nativo 'input'
    DOM->>DOM: React asigna ref.current = HTMLInputElement
    DOM->>Effect: Ejecuta useEffect()
    Note over Effect: Seguro acceder a ref.current (DOM listo)

    3. Reenvío de Referencias (forwardRef) y Encapsulamiento (useImperativeHandle)

    Por defecto, los componentes funcionales no aceptan la propiedad ref. Para permitir que un componente padre acceda a un nodo interno de un componente hijo, se utiliza forwardRef.

    flowchart TD
    subgraph SinForwardRef ["❌ Componente Estándar (Sin forwardRef)"]
        Padre1["Componente Padre"] -->|Pasa prop ref| Hijo1["&lt;MiInput ref={inputRef} /&gt;"]
        Hijo1 --> Error1["Error: ref no es una prop válida"]
    end

    subgraph ConForwardRef ["✅ Reenvío con forwardRef"]
        Padre2["Componente Padre"] -->|Reenvía ref| ForwardHijo["forwardRef((props, ref) => ...)"]
        ForwardHijo -->|Asigna ref al DOM interno| InputDOM["&lt;input ref={ref} /&gt;"]
    end

    3.1. Encapsulamiento Imperativo con useImperativeHandle

    Para no exponer todo el nodo DOM nativo al padre, useImperativeHandle limita los métodos expuestos:

    import React, { useRef, forwardRef, useImperativeHandle, useState } from 'react';

export interface ModalHandle {
  abrir: () => void;
  cerrar: () => void;
}

interface ModalProps {
  titulo: string;
  children: React.ReactNode;
}

export const ModalImperativo = forwardRef<ModalHandle, ModalProps>(
  ({ titulo, children }, ref) => {
    const [visible, setVisible] = useState<boolean>(false);

    useImperativeHandle(ref, () => ({
      abrir() {
        setVisible(true);
      },
      cerrar() {
        setVisible(false);
      },
    }));

    if (!visible) return null;

    return (
      <div className="fixed inset-0 bg-black/50 flex items-center justify-center p-4">
        <div className="bg-white rounded-xl p-6 max-w-md w-full shadow-2xl space-y-4">
          <h3 className="text-xl font-bold text-slate-900">{titulo}</h3>
          <div className="text-slate-600">{children}</div>
          <button
            onClick={() => setVisible(false)}
            className="px-4 py-2 bg-slate-800 text-white rounded-lg hover:bg-slate-700 transition"
          >
            Cerrar
          </button>
        </div>
      </div>
    );
  }
);

ModalImperativo.displayName = 'ModalImperativo';

    4. Demostración Práctica Completa: Canvas Interactivo con API Imperativa

    import React, { useRef, useState, forwardRef, useImperativeHandle } from 'react';

export interface PizarraHandle {
  limpiar: () => void;
  exportarImagen: () => string | null;
}

interface PizarraProps {
  color: string;
  grosor: number;
}

export const PizarraCanvas = forwardRef<PizarraHandle, PizarraProps>(
  ({ color, grosor }, ref) => {
    const canvasRef = useRef<HTMLCanvasElement>(null);
    const dibujandoRef = useRef<boolean>(false);
    const ultimasCoordsRef = useRef<{ x: number; y: number }>({ x: 0, y: 0 });

    useImperativeHandle(ref, () => ({
      limpiar() {
        const canvas = canvasRef.current;
        if (canvas) {
          const ctx = canvas.getContext('2d');
          ctx?.clearRect(0, 0, canvas.width, canvas.height);
        }
      },
      exportarImagen() {
        return canvasRef.current ? canvasRef.current.toDataURL('image/png') : null;
      },
    }));

    const handleMouseDown = (e: React.MouseEvent<HTMLCanvasElement>) => {
      dibujandoRef.current = true;
      const rect = canvasRef.current?.getBoundingClientRect();
      if (rect) {
        ultimasCoordsRef.current = {
          x: e.clientX - rect.left,
          y: e.clientY - rect.top,
        };
      }
    };

    const handleMouseUp = () => {
      dibujandoRef.current = false;
    };

    const handleMouseMove = (e: React.MouseEvent<HTMLCanvasElement>) => {
      if (!dibujandoRef.current || !canvasRef.current) return;
      const canvas = canvasRef.current;
      const ctx = canvas.getContext('2d');
      const rect = canvas.getBoundingClientRect();

      if (ctx && rect) {
        const xActual = e.clientX - rect.left;
        const yActual = e.clientY - rect.top;

        ctx.beginPath();
        ctx.strokeStyle = color;
        ctx.lineWidth = grosor;
        ctx.lineCap = 'round';
        ctx.moveTo(ultimasCoordsRef.current.x, ultimasCoordsRef.current.y);
        ctx.lineTo(xActual, yActual);
        ctx.stroke();

        ultimasCoordsRef.current = { x: xActual, y: yActual };
      }
    };

    return (
      <canvas
        ref={canvasRef}
        width={600}
        height={350}
        onMouseDown={handleMouseDown}
        onMouseUp={handleMouseUp}
        onMouseLeave={handleMouseUp}
        onMouseMove={handleMouseMove}
        className="border-2 border-slate-300 rounded-lg bg-white cursor-crosshair shadow-inner"
      />
    );
  }
);

PizarraCanvas.displayName = 'PizarraCanvas';
