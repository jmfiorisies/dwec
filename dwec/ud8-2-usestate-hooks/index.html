    Subunidad 9.2: Estado Local con useState y Custom Hooks en React

    1. Anatomía y Mecánica Interna del Hook useState

    El estado de un componente es la memoria interna que almacena datos dinámicos a lo largo del tiempo. Mientras que las props son inmutables y provienen del componente padre, el estado local es creado, gestionado y modificado de forma privada por el propio componente.

    En React, los componentes funcionales utilizan el hook useState para declarar variables de estado que persisten entre los ciclos de renderizado.

    1.1. Declaración, Desestructuración y Tipado con TypeScript

    La llamada a useState devuelve un par en forma de array de dos elementos (usando la sintaxis de desestructuración de ES6):

    1. La variable de estado: Contiene el valor actual persistido por React.
    2. La función actualizadora (dispatcher): Permite programar un cambio de estado e indicar a React que debe volver a renderizar el componente.
    import React, { useState } from 'react';

// Tipado explícito con TypeScript mediante genéricos
export function Contador() {
  // useState<number> especifica que el estado solo aceptará valores numéricos
  const [contador, setContador] = useState<number>(0);

  return (
    <div>
      <p>Contador actual: {contador}</p>
      <button onClick={() => setContador(contador + 1)}>Incrementar</button>
    </div>
  );
}

    Inferencia de Tipos vs. Genéricos Explícitos:

    • Inferencia automática: Si el valor inicial es un primitivo (useState(0), useState('Hola'), useState(true)), TypeScript infiere el tipo automáticamente.
    • Genéricos explícitos (useState<T>): Obligatorios cuando el estado puede ser null, undefined, o un tipo complejo (interfaz/unión):
    interface Usuario {
  id: number;
  nombre: string;
}

// El estado inicia como null y posteriormente albergará un objeto de tipo Usuario
const [usuario, setUsuario] = useState<Usuario | null>(null);

    1.2. Inicialización Perezosa (Lazy Initial State)

    Si la inicialización del estado requiere un cálculo pesado (como leer localStorage, parsear un JSON grande o realizar un procesamiento complejo), pasar el resultado directo a useState provocará que dicha función se ejecute en cada renderizado del componente, degradando el rendimiento.

    Para evitarlo, se utiliza la inicialización perezosa pasando una función de inicialización:

    // ❌ INCORRECTO: 'obtenerEstadoPesado()' se ejecuta en CADA re-renderizado
const [config, setConfig] = useState(obtenerEstadoPesado());

// ✅ CORRECTO: La función de inicialización SOLO se ejecuta en el montaje inicial
const [config, setConfig] = useState(() => obtenerEstadoPesado());

    2. El Principio de Inmutabilidad en la Gestión del Estado

    React utiliza una estrategia de diferenciación por referencia (Referential Equality Check) para determinar si el estado ha cambiado. Si la referencia en memoria del nuevo estado es idéntica a la del estado anterior, React asume que no hay cambios y omite el re-renderizado (bailout).

    $$\text{Referencia Anterior} === \text{Referencia Nueva} \implies \text{No hay re-renderizado}$$

    Por tanto, el estado en React debe tratarse como estrictamente inmutable. Nunca se deben modificar las propiedades de un objeto o los elementos de un array directamente.

    2.1. Manipulación Inmutable de Objetos

    Para actualizar un estado que contiene un objeto, se debe crear un nuevo objeto que copie las propiedades existentes e introduzca los cambios deseados utilizando el operador de propagación (Spread Operator ...).

    interface PerfilUsuario {
  nombre: string;
  email: string;
  preferencias: {
    tema: 'claro' | 'oscuro';
    notificaciones: boolean;
  };
}

export function FormularioPerfil() {
  const [perfil, setPerfil] = useState<PerfilUsuario>({
    nombre: 'Ana',
    email: 'ana@example.com',
    preferencias: {
      tema: 'claro',
      notificaciones: true,
    },
  });

  // ❌ INCORRECTO: Mutación directa
  const handleCambiarTemaIncorrecto = () => {
    perfil.preferencias.tema = 'oscuro'; // No cambia la referencia en memoria
    setPerfil(perfil); // React NO re-renderiza
  };

  // ✅ CORRECTO: Copia inmutable con operador Spread
  const handleCambiarTemaCorrecto = () => {
    setPerfil({
      ...perfil, // Copia el nivel superior (nombre, email)
      preferencias: {
        ...perfil.preferencias, // Copia el objeto anidado
        tema: 'oscuro', // Sobrescribe la propiedad específica
      },
    });
  };

  return (
    <button onClick={handleCambiarTemaCorrecto}>
      Cambiar a tema oscuro
    </button>
  );
}

    2.2. Manipulación Inmutable de Arrays

    A la hora de trabajar con listas en el estado, se deben evitar los métodos de array que mutan el array original (push, pop, splice, sort, reverse) y emplear métodos que devuelven nuevas instancias (map, filter, concat, destructuring):

    Operación Método Mutador (❌ Prohibido en React) Método Inmutable (✅ Recomendado)
    Añadir elemento array.push(item) [...array, item]
    Eliminar elemento array.splice(index, 1) array.filter(item => item.id !== idTarget)
    Modificar elemento array[index] = nuevoItem array.map(item => item.id === id ? nuevo : item)
    Ordenar lista array.sort() [...array].sort() o array.toSorted() 
    interface ItemCarrito {
  id: number;
  nombre: string;
  cantidad: number;
}

export function GestorCarrito() {
  const [items, setItems] = useState<ItemCarrito[]>([]);

  // 1. Añadir Elemento
  const agregarItem = (nuevo: ItemCarrito) => {
    setItems([...items, nuevo]);
  };

  // 2. Eliminar Elemento por ID
  const eliminarItem = (idEliminar: number) => {
    setItems(items.filter((item) => item.id !== idEliminar));
  };

  // 3. Incrementar Cantidad de un Elemento
  const incrementarCantidad = (idTarget: number) => {
    setItems(
      items.map((item) => {
        if (item.id === idTarget) {
          return { ...item, cantidad: item.cantidad + 1 };
        }
        return item; // Devuelve los elementos no modificados sin alterar
      })
    );
  };
}

    3. Actualizaciones Funcionales y Automatic Batching

    3.1. El Problema del Estado Desactualizado (Stale State)

    Las funciones actualizadoras devueltas por useState son asíncronas desde la perspectiva de la ejecución del código. React encola las actualizaciones para procesarlas de forma eficiente.

    Si intentamos leer el estado inmediatamente después de invocar su función actualizadora, obtendremos el valor del estado en el renderizado actual, no el valor actualizado:

    const [contador, setContador] = useState(0);

const handleMultipleIncrementoIncorrecto = () => {
  // Supongamos que contador = 0
  setContador(contador + 1); // Encola: setContador(0 + 1)
  setContador(contador + 1); // Encola: setContador(0 + 1)
  setContador(contador + 1); // Encola: setContador(0 + 1)
  // Resultado final tras el re-render: contador = 1 (¡NO 3!)
};

    3.2. Actualizaciones de Estado Funcionales

    Para resolver la lectura de estados obsoletos cuando una actualización depende del valor inmediatamente anterior, se debe pasar una función actualizadora en lugar de un valor directo:

    const handleMultipleIncrementoCorrecto = () => {
  // React pasa el valor más reciente acumulado en la cola como 'prev'
  setContador((prev) => prev + 1); // prev = 0 -> retorna 1
  setContador((prev) => prev + 1); // prev = 1 -> retorna 2
  setContador((prev) => prev + 1); // prev = 2 -> retorna 3
  // Resultado final tras el re-render: contador = 3
};

    3.3. Agrupamiento Automático (Automatic Batching)

    A partir de React 18, la librería aplica Automatic Batching (agrupamiento automático) de forma nativa. Esto significa que múltiples cambios de estado desencadenados dentro del mismo evento (incluso dentro de promesas, setTimeout o manejadores asíncronos) se agrupan en un único ciclo de re-renderizado:

    const handleOperacionMultiple = async () => {
  const datos = await fetchDatos();

  // A pesar de haber 3 llamadas a funciones actualizadoras, 
  // React 18 solo realizará UN ÚNICO re-renderizado de la interfaz
  setDatos(datos);
  setCargando(false);
  setError(null);
};

    4. Elevación del Estado (Lifting State Up)

    Cuando dos o más componentes de la jerarquía necesitan compartir un mismo estado o reaccionar a cambios comunes, el estado no debe duplicarse en cada uno de ellos.

    El patrón Lifting State Up consiste en elevar el estado al ancestro común más cercano de los componentes que lo necesitan. El ancestro gestiona el estado y lo distribuye hacia abajo mediante props:

        Padre1["Padre (Sin Estado)"]
        HijoA1["Hijo A (useState: cuenta)"]
        HijoB1["Hijo B (useState: cuenta)"]
        Padre1 --> HijoA1
        Padre1 --> HijoB1
    end

    subgraph JerarquiaCorrecta ["✅ Estado Elevado (Lifting State Up)"]
        Padre2["Padre (useState: cuenta)"]
        HijoA2["Hijo A (props: cuenta, onIncrementar)"]
        HijoB2["Hijo B (props: cuenta)"]
        Padre2 -->|"Props (cuenta, callback)"| HijoA2
        Padre2 -->|"Props (cuenta)"| HijoB2
    end

    Ejemplo de Elevación del Estado

    import React, { useState } from 'react';

// --- HIJO 1: Control de entrada ---
interface SelectorTemperaturaProps {
  temperatura: number;
  onTemperaturaChange: (nuevaTemp: number) => void;
}

function SelectorTemperatura({ temperatura, onTemperaturaChange }: SelectorTemperaturaProps) {
  return (
    <input
      type="number"
      value={temperatura}
      onChange={(e) => onTemperaturaChange(Number(e.target.value))}
    />
  );
}

// --- HIJO 2: Visualización derivada ---
function PanelEbullicion({ celsius }: { celsius: number }) {
  if (celsius >= 100) {
    return <p className="alerta-exito">El agua herviría a esta temperatura.</p>;
  }
  return <p className="alerta-info">El agua no herviría.</p>;
}

// --- ANCESTRO COMÚN: Posee el estado elevado ---
export function CalculadoraTermica() {
  const [temperatura, setTemperatura] = useState<number>(20);

  return (
    <div>
      <h3>Termómetro Interactivo</h3>
      <SelectorTemperatura 
        temperatura={temperatura} 
        onTemperaturaChange={setTemperatura} 
      />
      <PanelEbullicion celsius={temperatura} />
    </div>
  );
}

    5. Extracción y Encapsulación en Custom Hooks

    Un Custom Hook es una función de JavaScript que permite extraer la lógica de estado y de interacción fuera de los componentes visuales para hacerla reutilizable, mantenible y testeable.

    5.1. Reglas Estrictas de los Hooks (Rules of Hooks)

    Para asegurar que React pueda asociar las celdas de estado con los componentes correspondientes, se deben cumplir dos reglas fundamentales:

    1. Solo llamar a Hooks en el nivel superior (Top-Level): Nunca llamar a un hook dentro de bucles (for), condiciones (if), funciones anidadas o bloques try/catch.
    2. Solo llamar a Hooks desde funciones de React: Invocarlos exclusivamente desde componentes funcionales o desde dentro de otros Custom Hooks.
    3. Convención de nomenclatura: El nombre de un Custom Hook debe comenzar obligatoriamente con el prefijo use (useContador, useFormulario, useCarrito).

    5.2. Ejemplo de Custom Hook: useContador

    A continuación se muestra cómo abstraer la lógica de un contador con límites e incremento parametrizado:

    import { useState } from 'react';

interface OpcionesContador {
  valorInicial?: number;
  minimo?: number;
  maximo?: number;
}

export function useContador({
  valorInicial = 0,
  minimo = -Infinity,
  maximo = Infinity,
}: OpcionesContador = {}) {
  const [contador, setContador] = useState<number>(valorInicial);

  const incrementar = (paso: number = 1) => {
    setContador((prev) => Math.min(prev + paso, maximo));
  };

  const decrementar = (paso: number = 1) => {
    setContador((prev) => Math.max(prev - paso, minimo));
  };

  const reiniciar = () => {
    setContador(valorInicial);
  };

  // Retornamos un objeto con el estado y los métodos de actualización
  return {
    contador,
    incrementar,
    decrementar,
    reiniciar,
  };
}

    Consumo del Custom Hook en un Componente:

    import React from 'react';
import { useContador } from './useContador';

export function ComponenteContadorModular() {
  const { contador, incrementar, decrementar, reiniciar } = useContador({
    valorInicial: 5,
    minimo: 0,
    maximo: 10,
  });

  return (
    <div className="card">
      <h4>Cantidad Seleccionada: {contador}</h4>
      <button onClick={() => decrementar()}>-</button>
      <button onClick={() => incrementar()}>+</button>
      <button onClick={reiniciar}>Reiniciar</button>
    </div>
  );
}

    6. Demostración Práctica Completa: Aplicación de Carrito de Compras

    Esta aplicación integra todos los conceptos vistos en la subunidad 9.2:

    • Estado local tipado con TypeScript.
    • Operaciones inmutables sobre arrays y objetos.
    • Actualizaciones de estado funcionales.
    • Elevación de estado (Lifting State Up).
    • Custom Hook reutilizable (useCarrito).
    import React, { useState } from 'react';

// --- 1. MODELOS DE DATOS ---
export interface Producto {
  id: number;
  nombre: string;
  precio: number;
}

export interface ItemCarrito extends Producto {
  cantidad: number;
}

// --- 2. CUSTOM HOOK: Encapsula la lógica de negocio del Carrito ---
export function useCarrito() {
  const [items, setItems] = useState<ItemCarrito[]>([]);

  const agregarProducto = (producto: Producto) => {
    setItems((prevItems) => {
      const existe = prevItems.find((item) => item.id === producto.id);
      if (existe) {
        return prevItems.map((item) =>
          item.id === producto.id
            ? { ...item, cantidad: item.cantidad + 1 }
            : item
        );
      }
      return [...prevItems, { ...producto, cantidad: 1 }];
    });
  };

  const cambiarCantidad = (id: number, delta: number) => {
    setItems((prevItems) =>
      prevItems
        .map((item) => {
          if (item.id === id) {
            const nuevaCantidad = item.cantidad + delta;
            return nuevaCantidad > 0 ? { ...item, cantidad: nuevaCantidad } : null;
          }
          return item;
        })
        .filter((item): item is ItemCarrito => item !== null)
    );
  };

  const vaciarCarrito = () => setItems([]);

  const totalPrecio = items.reduce(
    (acc, item) => acc + item.precio * item.cantidad,
    0
  );

  return { items, agregarProducto, cambiarCantidad, vaciarCarrito, totalPrecio };
}

// --- 3. COMPONENTE HIJO: Lista de Productos Disponibles ---
const PRODUCTOS_CATALOGO: Producto[] = [
  { id: 1, nombre: 'Teclado Mecánico RGB', precio: 89.99 },
  { id: 2, nombre: 'Ratón Ergonómico Inalámbrico', precio: 45.50 },
  { id: 3, nombre: 'Monitor 27" 4K', precio: 299.00 },
];

interface CatalogoProps {
  onAgregar: (producto: Producto) => void;
}

function CatalogoProductos({ onAgregar }: CatalogoProps) {
  return (
    <div className="catalogo-box">
      <h3>Catálogo de Productos</h3>
      <ul>
        {PRODUCTOS_CATALOGO.map((prod) => (
          <li key={prod.id} style={{ marginBottom: '8px' }}>
            <span>{prod.nombre} - {prod.precio.toFixed(2)}€</span>
            <button 
              onClick={() => onAgregar(prod)} 
              style={{ marginLeft: '10px' }}
            >
              Añadir al Carrito
            </button>
          </li>
        ))}
      </ul>
    </div>
  );
}

// --- 4. COMPONENTE HIJO: Vista Resumen del Carrito ---
interface VistaCarritoProps {
  items: ItemCarrito[];
  total: number;
  onCambiarCantidad: (id: number, delta: number) => void;
  onVaciar: () => void;
}

function VistaCarrito({ items, total, onCambiarCantidad, onVaciar }: VistaCarritoProps) {
  if (items.length === 0) {
    return <p>El carrito está vacío.</p>;
  }

  return (
    <div className="carrito-box">
      <h3>Tu Carrito</h3>
      <ul>
        {items.map((item) => (
          <li key={item.id} style={{ marginBottom: '6px' }}>
            <strong>{item.nombre}</strong> - {item.precio.toFixed(2)}€ x {item.cantidad}
            <button onClick={() => onCambiarCantidad(item.id, 1)} style={{ marginLeft: '6px' }}>+</button>
            <button onClick={() => onCambiarCantidad(item.id, -1)} style={{ marginLeft: '4px' }}>-</button>
          </li>
        ))}
      </ul>
      <h4>Total: {total.toFixed(2)}€</h4>
      <button onClick={onVaciar}>Vaciar Carrito</button>
    </div>
  );
}

// --- 5. COMPONENTE PRINCIPAL (ORQUESTADOR) ---
export function AplicacionTienda() {
  const { items, agregarProducto, cambiarCantidad, vaciarCarrito, totalPrecio } = useCarrito();

  return (
    <div style={{ maxWidth: '600px', margin: '20px auto', fontFamily: 'sans-serif' }}>
      <h2>Tienda en Línea DWEC</h2>
      <hr />
      <CatalogoProductos onAgregar={agregarProducto} />
      <hr />
      <VistaCarrito 
        items={items} 
        total={totalPrecio} 
        onCambiarCantidad={cambiarCantidad} 
        onVaciar={vaciarCarrito} 
      />
    </div>
  );
}
