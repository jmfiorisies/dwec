    10.1: Formularios Controlados y No Controlados en React

    1. Fundamentos y Filosofía de Control en Componentes de Formulario

    En el entorno del navegador web nativo, los elementos de formulario HTML (<input>, <textarea>, <select>) mantienen su propio estado interno en el DOM real. Cuando un usuario escribe un carácter en un campo de texto, el navegador actualiza la propiedad .value del nodo nativo de forma imperativa sin requerir intervención de ningún script externo.

    En React, el paradigma principal establece que el estado de la aplicación debe residir en el Virtual DOM y ser la única fuente de verdad (Single Source of Truth). Esto genera una dualidad fundamental al trabajar con elementos interactivos de entrada:

    1. ¿Debe el DOM del navegador gestionar el estado de los datos introducidos?
    2. ¿Debe React tomar el control absoluto de cada carácter tecleado mediante su propio estado local (useState)?

    La respuesta define la arquitectura del formulario, dividiéndose en Componentes Controlados y Componentes No Controlados.

    2. Componentes Controlados: Sincronización Directa con useState

    Un componente controlado es aquel en el que React asigna el valor del campo a través de la propiedad value (o checked en checkboxes) y escucha los cambios mediante el manejador onChange.

    $$\text{Pulsación} \longrightarrow \text{Disparo de } \text{onChange} \longrightarrow \text{Actualización de Estado } (\text{setState}) \longrightarrow \text{Re-render} \longrightarrow \text{Actualización del } \text{value}$$

    2.1. Manejo Multi-campo con Único Objeto de Estado y Tailwind CSS

    El patrón recomendado para formularios con múltiples entradas consiste en agrupar el estado en un único objeto y utilizar una función manejadora genérica apoyada en la propiedad name del elemento HTML:

    import React, { useState } from 'react';

interface FormularioRegistroState {
  username: string;
  email: string;
  rol: 'admin' | 'user' | 'guest';
  aceptaTerminos: boolean;
  comentarios: string;
}

export function FormularioRegistroControlado() {
  const [formData, setFormData] = useState<FormularioRegistroState>({
    username: '',
    email: '',
    rol: 'user',
    aceptaTerminos: false,
    comentarios: '',
  });

  const handleChange = (
    e: React.ChangeEvent<HTMLInputElement | HTMLSelectElement | HTMLTextAreaElement>
  ) => {
    const { name, value, type } = e.target;
    const valorFinal = type === 'checkbox' ? (e.target as HTMLInputElement).checked : value;

    setFormData((prev) => ({
      ...prev,
      [name]: valorFinal,
    }));
  };

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    console.log('Datos listos para enviar al servidor:', formData);
  };

  return (
    <form onSubmit={handleSubmit} className="max-w-md mx-auto p-6 bg-white rounded-xl shadow-md space-y-4 border border-slate-200">
      <h2 className="text-xl font-bold text-slate-800">Registro de Usuario (Controlado)</h2>

      {/* Campo Texto */}
      <div>
        <label htmlFor="username" className="block text-sm font-medium text-slate-700 mb-1">Usuario:</label>
        <input
          type="text"
          id="username"
          name="username"
          value={formData.username}
          onChange={handleChange}
          className="w-full px-3 py-2 border border-slate-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
        />
      </div>

      {/* Campo Email */}
      <div>
        <label htmlFor="email" className="block text-sm font-medium text-slate-700 mb-1">Correo Electrónico:</label>
        <input
          type="email"
          id="email"
          name="email"
          value={formData.email}
          onChange={handleChange}
          className="w-full px-3 py-2 border border-slate-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
        />
      </div>

      {/* Select */}
      <div>
        <label htmlFor="rol" className="block text-sm font-medium text-slate-700 mb-1">Rol de Usuario:</label>
        <select
          id="rol"
          name="rol"
          value={formData.rol}
          onChange={handleChange}
          className="w-full px-3 py-2 border border-slate-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500 bg-white"
        >
          <option value="user">Usuario Estándar</option>
          <option value="admin">Administrador</option>
          <option value="guest">Invitado</option>
        </select>
      </div>

      {/* Checkbox */}
      <div className="flex items-center space-x-2">
        <input
          type="checkbox"
          id="aceptaTerminos"
          name="aceptaTerminos"
          checked={formData.aceptaTerminos}
          onChange={handleChange}
          className="h-4 w-4 text-blue-600 focus:ring-blue-500 border-slate-300 rounded"
        />
        <label htmlFor="aceptaTerminos" className="text-sm text-slate-600">Acepto los términos y condiciones</label>
      </div>

      {/* Textarea */}
      <div>
        <label htmlFor="comentarios" className="block text-sm font-medium text-slate-700 mb-1">Comentarios:</label>
        <textarea
          id="comentarios"
          name="comentarios"
          rows={3}
          value={formData.comentarios}
          onChange={handleChange}
          className="w-full px-3 py-2 border border-slate-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
        />
      </div>

      <button
        type="submit"
        disabled={!formData.aceptaTerminos}
        className="w-full py-2 px-4 bg-blue-600 text-white font-semibold rounded-lg hover:bg-blue-700 disabled:bg-slate-300 disabled:cursor-not-allowed transition-colors"
      >
        Registrar
      </button>
    </form>
  );
}

    3. Componentes No Controlados: Delegación en el DOM (useRef y FormData)

    Un componente no controlado mantiene el estado de sus campos directamente en el árbol DOM del navegador. En lugar de escribir un manejador onChange para cada actualización de carácter, se emplea defaultValue o la API FormData para extraer los datos puntualmente al enviar.

    3.1. Procesamiento Global Eficiente con FormData

    import React from 'react';

export function FormularioNoControladoFormData() {
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    const formData = new FormData(e.currentTarget);
    const datosFormulario = Object.fromEntries(formData.entries());

    console.log('Objeto de datos procesado con FormData:', datosFormulario);
  };

  return (
    <form onSubmit={handleSubmit} className="max-w-md mx-auto p-6 bg-slate-50 rounded-xl border border-slate-200 space-y-4">
      <h3 className="text-lg font-bold text-slate-800">Publicar Artículo (No Controlado)</h3>

      <input
        type="text"
        name="titulo"
        defaultValue="Título por Defecto"
        placeholder="Título del Artículo"
        className="w-full px-3 py-2 border border-slate-300 rounded-lg"
      />

      <textarea
        name="contenido"
        defaultValue="Contenido inicial del artículo..."
        rows={4}
        className="w-full px-3 py-2 border border-slate-300 rounded-lg"
      />

      {/* Caso de uso ideal: Subida de archivos nativa */}
      <div>
        <label className="block text-sm font-medium text-slate-700 mb-1">Adjuntar documento:</label>
        <input type="file" name="adjunto" className="text-sm text-slate-500 file:mr-4 file:py-2 file:px-4 file:rounded-md file:border-0 file:bg-blue-50 file:text-blue-700 hover:file:bg-blue-100" />
      </div>

      <button type="submit" className="w-full py-2 bg-slate-800 text-white rounded-lg hover:bg-slate-900 transition-colors">
        Publicar
      </button>
    </form>
  );
}

    end

    Cuadro Comparativo de Selección

    Criterio / Funcionalidad Componente Controlado (useState) Componente No Controlado (useRef / FormData)
    Fuente de Verdad Estado local en React Virtual DOM Nodos del DOM Real del Navegador
    Rendimiento de Escritura Re-renderiza en cada pulsación ($O(N)$) Sin re-renders durante la escritura ($O(1)$)
    Validación Instantánea Sencilla: Se valida el estado en cada render Requiere escuchadores manuales al DOM
    Entradas de Archivos (<input type="file">) Solo Lectura (Por seguridad del navegador) Enfoque Natural e Ideal

    5. Demostración Práctica Completa: Panel de Configuración Híbrido

    A continuación se expone una implementación en TypeScript que combina componentes controlados (para validación en vivo), componentes no controlados con useRef** (para subida de archivos) y Tailwind CSS**:

    import React, { useState, useRef } from 'react';

interface NotificacionConfig {
  id: string;
  canal: string;
  activo: boolean;
}

interface PerfilUsuarioState {
  nombreCompleto: string;
  biografia: string;
  notificaciones: NotificacionConfig[];
}

export function PanelConfiguracionHibrido() {
  const [perfil, setPerfil] = useState<PerfilUsuarioState>({
    nombreCompleto: 'Alex Dev',
    biografia: 'Desarrollador Frontend.',
    notificaciones: [
      { id: '1', canal: 'Email Diario', activo: true },
      { id: '2', canal: 'SMS de Seguridad', activo: false },
    ],
  });

  const avatarInputRef = useRef<HTMLInputElement>(null);

  const handleTextoChange = (e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement>) => {
    const { name, value } = e.target;
    setPerfil((prev) => ({ ...prev, [name]: value }));
  };

  const handleToggleNotificacion = (id: string) => {
    setPerfil((prev) => ({
      ...prev,
      notificaciones: prev.notificaciones.map((notif) =>
        notif.id === id ? { ...notif, activo: !notif.activo } : notif
      ),
    }));
  };

  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    const archivoAvatar = avatarInputRef.current?.files?.[0];

    const payloadFinal = {
      ...perfil,
      avatarNombreArchivo: archivoAvatar ? archivoAvatar.name : 'sin-cambios.png',
    };

    console.log('PAYLOAD HÍBRIDO ENVIADO:', payloadFinal);
    alert('Configuración guardada correctamente.');
  };

  const esNombreValido = perfil.nombreCompleto.trim().length >= 3;

  return (
    <div className="max-w-xl mx-auto my-8 p-6 bg-white border border-slate-200 rounded-xl shadow-lg space-y-6">
      <h2 className="text-2xl font-bold text-slate-800 border-b pb-3">Configuración de Perfil</h2>

      <form onSubmit={handleSubmit} className="space-y-6">
        {/* Sección Controlada */}
        <fieldset className="p-4 bg-slate-50 rounded-lg border border-slate-200 space-y-4">
          <legend className="px-2 text-sm font-semibold text-slate-700">Datos Personales (Controlados)</legend>

          <div>
            <label htmlFor="nombreCompleto" className="block text-sm font-medium text-slate-700">Nombre Completo (*mínimo 3 caracteres):</label>
            <input
              type="text"
              id="nombreCompleto"
              name="nombreCompleto"
              value={perfil.nombreCompleto}
              onChange={handleTextoChange}
              className="mt-1 w-full px-3 py-2 border border-slate-300 rounded-md focus:ring-2 focus:ring-blue-500"
            />
            {!esNombreValido && <span className="text-xs text-red-500 mt-1 block">El nombre es demasiado corto</span>}
          </div>

          <div>
            <label htmlFor="biografia" className="block text-sm font-medium text-slate-700">Biografía:</label>
            <textarea
              id="biografia"
              name="biografia"
              rows={2}
              value={perfil.biografia}
              onChange={handleTextoChange}
              className="mt-1 w-full px-3 py-2 border border-slate-300 rounded-md focus:ring-2 focus:ring-blue-500"
            />
          </div>
        </fieldset>

        {/* Sección No Controlada */}
        <fieldset className="p-4 bg-slate-50 rounded-lg border border-slate-200">
          <legend className="px-2 text-sm font-semibold text-slate-700">Fotografía de Perfil (No Controlado)</legend>
          <input type="file" ref={avatarInputRef} accept="image/*" className="mt-2 text-sm text-slate-500" />
        </fieldset>

        {/* Sección Dinámica */}
        <fieldset className="p-4 bg-slate-50 rounded-lg border border-slate-200 space-y-2">
          <legend className="px-2 text-sm font-semibold text-slate-700">Canales de Notificación</legend>
          {perfil.notificaciones.map((notif) => (
            <label key={notif.id} className="flex items-center space-x-3 cursor-pointer">
              <input
                type="checkbox"
                checked={notif.activo}
                onChange={() => handleToggleNotificacion(notif.id)}
                className="h-4 w-4 text-blue-600 rounded"
              />
              <span className="text-sm text-slate-700">{notif.canal}</span>
            </label>
          ))}
        </fieldset>

        <button
          type="submit"
          disabled={!esNombreValido}
          className="w-full py-2.5 bg-blue-600 text-white font-bold rounded-lg hover:bg-blue-700 disabled:bg-slate-300 transition-colors"
        >
          Guardar Cambios
        </button>
      </form>
    </div>
  );
}
