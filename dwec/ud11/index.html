    UD 11: Entorno BOM, useEffect y Rutas (RA6) — Visión General y Mapa Curricular

    1. Presentación y Contextualización Curricular

    La Unidad Didáctica 11 constituye el puente definitivo entre el renderizado reactivo y declarativo de React y el entorno de ejecución externo en el navegador (Browser Object Model - BOM, almacenamiento, red y navegación). Tras haber dominado la gestión del estado, formularios, manipulación segura del DOM y técnicas de optimización en la UD 10, esta unidad aborda la sincronización con sistemas externos y la arquitectura de navegación en aplicaciones de página única (SPA - Single Page Application).

    En el ecosistema de React, la función del componente debe mantenerse pura durante la fase de render. Sin embargo, las aplicaciones profesionales reales dependen de efectos secundarios (side effects): peticiones HTTP asíncronas, suscripciones a eventos de la ventana (window), almacenamiento local (localStorage), temporizadores y navegación cliente sin recarga de página.

    Esta unidad integra dos pilares estructurales:

    1. Sincronización y Ciclo de Vida (useEffect y APIs BOM): Gestión rigurosa del ciclo de vida funcional (montaje, actualización y desmontaje), limpieza de recursos (cleanup functions), prevención de fugas de memoria (memory leaks) e interacción con las APIs del navegador (window, navigator, localStorage, sessionStorage).
    2. Enrutamiento Cliente y Arquitectura SPA (React Router v6/v7): Declaración de rutas estáticas y dinámicas, gestión de parámetros (useParams, useSearchParams), navegación programática (useNavigate), rutas anidadas (nested routes con <Outlet/>) y protección de rutas mediante componentes de guarda.

    2. Resultado de Aprendizaje y Criterios de Evaluación (RA6)

    Esta unidad didáctica consolida y expande el Resultado de Aprendizaje 6 (RA6) del módulo profesional de Desarrollo Web en Entorno Cliente (DWEC):

    RA6: Optimiza el rendimiento de aplicaciones web en el entorno cliente controlando el ciclo de vida del dibujado, aplicando técnicas de reconciliación del Virtual DOM y gestionando accesos imperativos al DOM de forma segura.

    Desglose Detallado de Criterios de Evaluación (CE):

    • CE6.h: Se ha controlado el ciclo de vida funcional de los componentes mediante el hook useEffect, distinguiendo las fases de montaje, actualización dependiente y desmontaje.
    • CE6.i: Se han implementado funciones de limpieza (cleanup functions) para cancelar suscripciones, limpiar temporizadores y abortar peticiones asíncronas pendientes (AbortController), evitando fugas de memoria.
    • CE6.j: Se han integrado las APIs nativas del Browser Object Model (BOM) y Web Storage (localStorage, sessionStorage, location, history) en el flujo reactivo de componentes.
    • CE6.k: Se ha diseñado la arquitectura de navegación cliente para una Single Page Application (SPA) utilizando React Router.
    • CE6.l: Se han gestionado rutas dinámicas extrayendo parámetros de URL (useParams) y parámetros de búsqueda (useSearchParams).
    • CE6.m: Se ha implementado un sistema de rutas anidadas con diseños reutilizables (layouts) apoyados en el componente <Outlet/>.
    • CE6.n: Se han desarrollado mecanismos de control de acceso y navegación programática (useNavigate) para proteger rutas privadas según el estado de autenticación.

    5. Justificación Pedagógica y Principios de Arquitectura

    5.1. La Mentalidad de Sincronización vs Ocurrencia de Eventos

    Un error habitual al aprender useEffect es tratarlo como los métodos tradicionales de ciclo de vida de componentes de clase (componentDidMount, componentDidUpdate, componentWillUnmount).

    En la arquitectura moderna de React, useEffect no es un receptor de eventos, es un mecanismo de sincronización.

    • Manejador de Eventos (Event Handler): Responde a una acción específica del usuario (p. ej., hacer clic en un botón de "Comprar"). Debe ir en la función de evento (handleClick).
    • Efecto (useEffect): Garantiza que el componente esté sincronizado con un sistema externo (servidor, canvas, suscripción a la red, localStorage) mientras dicho componente permanezca en la pantalla.

    $$\text{Efecto Correcto} = \text{Sincronizar el estado del componente con el sistema externo } X \text{ mientras } [deps] \text{ cambien}$$

    5.2. Enrutamiento Declarativo y Encapsulación de Vistas

    El uso de React Router transforma la arquitectura de la aplicación web:

    • Sin Recarga de Página: La URL cambia en la barra de direcciones utilizando la API history.pushState() del BOM, ofreciendo una experiencia fluida e instantánea.
    • Composición Jerárquica: Los diseños compartidos (cabeceras, barras laterales, pies de página) no se vuelven a renderizar al cambiar de vista. El componente <Outlet/> actúa como marcador de posición donde se inyectan dinámicamente las rutas hijas.
    • Seguridad y Accesibilidad: La protección de rutas privadas mediante componentes encapsulados (Guards) previene la renderización de información sensitive en el cliente antes de validar la autenticación o los roles del usuario.

    6. Cuadro Comparativo Integrado: Sincronización, Estado y Navegación

    Herramienta / Concepto Ámbito Propósito Principal Cuándo Utilizarlo
    useEffect React Hook Sincronizar un componente con una API o sistema externo tras el render. Peticiones HTTP, suscripciones BOM, temporizadores, localStorage.
    Cleanup Function Return de useEffect Cancelar procesos pendientes y liberar recursos al desmontar o re-ejecutar. clearInterval, removeEventListener, abortController.abort().
    BrowserRouter React Router Proveedor de contexto para la gestión del historial y URL del navegador. En la raíz de la aplicación (main.tsx o App.tsx).
    <Outlet/> React Router Punto de inserción para renderizar rutas anidadas dentro de un Layout. Vistas compartidas con barras laterales o paneles de navegación.
    useParams React Router Hook Extraer parámetros dinámicos definidos en la ruta (/usuario/:id). Páginas de detalle, fichas de producto, perfiles de usuario.
    useSearchParams React Router Hook Leer y modificar la query string de la URL (?page=2&sort=asc). Filtros de búsqueda, paginación, ordenación de tablas.
    useNavigate React Router Hook Redireccionar al usuario de forma programática tras un evento. Tras completar un formulario, iniciar sesión o cerrar sesión.
