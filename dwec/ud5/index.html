    1. El Modelo de Objetos del Documento (DOM Nativo) 🌳

    El DOM (Document Object Model) es una interfaz de programación (API) que representa los documentos HTML como una estructura jerárquica de árbol. Cada elemento, atributo y fragmento de texto en el HTML se transforma en un nodo que JavaScript puede inspeccionar, crear, modificar o eliminar en tiempo de ejecución.

    flowchart TD
    Window["window (Objeto Global)"] --> Document["document (Objeto Principal)"]
    Document --> Root["Elemento Raíz: <html>"]
    Root --> Head["<head>"]
    Root --> Body["<body>"]
    Head --> Title["<title> -> Texto"]
    Body --> Header["<header>"]
    Body --> Main["<main>"]
    Main --> Section["<section>"]
    Section --> H1["<h1> -> Texto"]
    Section --> P["<p> -> Texto"]

    Tipos de Nodos Principales

    • Document: Nodo raíz de todo el documento HTML.
    • Element: Cada una de las etiquetas HTML (<div>, <p>, <button>).
    • Text: El contenido textual dentro de un elemento.
    • Comment: Comentarios escritos dentro del HTML.

    Selección de Elementos en el DOM

    Para interactuar con la interfaz, primero es necesario seleccionar los nodos correspondientes. Se prioriza el uso de métodos modernos basados en selectores CSS.

    Método Retorna Actualización Notas
    document.getElementById('id') Element o null N/A Muy rápido, busca por ID único.
    document.querySelector('selector') Element o null N/A Retorna la primera coincidencia CSS.
    document.querySelectorAll('selector') NodeList Estática Retorna todas las coincidencias. Permite forEach.
    document.getElementsByClassName('clase') HTMLCollection Viva No tiene métodos funcionales como forEach. 
    // Selección moderna por selectores CSS
const botonEnviar = document.querySelector("#btn-submit");
const tarjetas = document.querySelectorAll(".card.active"); // NodeList

// Conversión de HTMLCollection / NodeList a Array real para usar map/filter
const tarjetasArray = Array.from(tarjetas);

    Recorrido del Árbol DOM (Traversal)

    Permite navegar entre nodos directamente utilizando las relaciones jerárquicas sin necesidad de re-consultar el documento.

    const elementoActual = document.querySelector(".tarjeta-activa");

// Navegación entre Elementos (Omite nodos de texto y comentarios)
const padre = elementoActual.parentElement;             // Contenedor padre
const hermanosSiguientes = elementoActual.nextElementSibling; // Siguiente hermano
const hermanoAnterior = elementoActual.previousElementSibling;// Hermano anterior
const primerHijo = elementoActual.firstElementChild;     // Primer hijo elemento
const todosHijos = elementoActual.children;             // HTMLCollection de hijos

    Creación, Modificación y Eliminación de Nodos

    Modificación de Contenido y Atributos

    const titulo = document.querySelector("#titulo-principal");

// textContent vs innerHTML
titulo.textContent = "Nuevo Título Seguro"; // SEGURO: Previene ataques XSS (interpreta todo como texto)
// titulo.innerHTML = "<span>Título</span>"; // ATENCIÓN: Renders HTML, vulnerable si se pasa input del usuario

// Manipulación de Atributos
titulo.setAttribute("data-categoria", "ofertas");
const categoria = titulo.getAttribute("data-categoria");
titulo.removeAttribute("disabled");

// Dataset (Atributos data-*)
console.log(titulo.dataset.categoria); // "ofertas"

    Gestor de Clases CSS (classList)

    const tarjeta = document.querySelector(".card");

tarjeta.classList.add("destacada", "sombra"); // Añade clases
tarjeta.classList.remove("oculta");            // Elimina clase
tarjeta.classList.toggle("activa");            // Alterna clase (añade si no existe, borra si existe)
const tieneSombra = tarjeta.classList.contains("sombra"); // true

    Inserción y Eliminación Dinámica con Alto Rendimiento

    Modificar el DOM genera operaciones costosas denominadas Reflow (recalculo de maquetación) y Repaint (redibujado gráfico). Para insertar múltiples elementos de forma eficiente se utiliza DocumentFragment o insertAdjacentHTML.

    const lista = document.querySelector("#lista-usuarios");
const usuarios = ["Ana", "Carlos", "Beatriz", "Elena"];

// OPCIÓN 1: DocumentFragment (Mantiene los cambios en memoria antes de inyectar)
const fragmento = document.createDocumentFragment();

usuarios.forEach((nombre) => {
  const li = document.createElement("LI");
  li.textContent = nombre;
  li.classList.add("item-usuario");
  fragmento.appendChild(li); // No impacta en el DOM real todavía
});

lista.appendChild(fragmento); // UN SOLO Reflow al insertar todo el conjunto

// OPCIÓN 2: insertAdjacentHTML (Inyección limpia de cadenas HTML)
// Posiciones: 'beforebegin', 'afterbegin', 'beforeend', 'afterend'
lista.insertAdjacentHTML("beforeend", `<li class="item-usuario">Nuevo Usuario</li>`);

// Eliminación de Nodos
const nodoAELiminar = document.querySelector("#elemento-obsoleto");
nodoAELiminar.remove(); // Eliminación directa

    2. Gestión de Eventos y Manejo de la Interacción ⚡

    Un Evento es una señal emitida por el navegador que indica que se ha producido una acción (click, movimiento del ratón, carga del documento, pulsación de tecla).

    Escuchadores de Eventos (addEventListener)

    const boton = document.querySelector("#btn-comprar");

function manejarClick(event) {
  event.preventDefault(); // Cancela la acción por defecto (ej: submit de un formulario o link)
  console.log("Elemento clickeado:", event.target); // Elemento que disparó el evento
  console.log("Elemento con listener:", event.currentTarget); // Elemento que escucha el evento
}

// Registro
boton.addEventListener("click", manejarClick);

// Eliminación (Requiere la referencia a una función nombrada, no anónima)
// boton.removeEventListener("click", manejarClick);

    Fases de Propagación de Eventos (Captura y Burbujeo)

    Cuando ocurre un evento en un elemento anidado, la señal recorre el árbol DOM en tres fases:

    flowchart TD
    subgraph Fase 1: Captura (Capture Phase)
    Window1["window"] --> Doc1["document"] --> Body1["<body>"] --> Div1["<div id='padre'>"]
    end

    subgraph Fase 2: Objetivo (Target Phase)
    Div1 --> Target["<button id='hijo'> (Elemento Objetivo)"]
    end

    subgraph Fase 3: Burbujeo (Bubbling Phase)
    Target --> Div2["<div id='padre'>"] --> Body2["<body>"] --> Doc2["document"] --> Window2["window"]
    end
    1. Fase de Captura (Capturing Phase): El evento desciende desde window hasta el elemento objetivo.
    2. Fase de Objetivo (Target Phase): El evento alcanza el nodo exacto que originó la acción.
    3. Fase de Burbujeo (Bubbling Phase): El evento asciende desde el elemento objetivo hasta la raíz window. Por defecto, los listeners se ejecutan en esta fase.
    // Detener la propagación
function detenerBurbujeo(e) {
  e.stopPropagation(); // Evita que el evento continúe ascendiendo a los elementos padres
}

    Patron Clave: Delegación de Eventos (Event Delegation)

    En lugar de adjuntar un escucha de eventos a cada elemento hijo (lo cual consume excesiva memoria y falla al añadir elementos dinámicos), se coloca un único escucha en el elemento padre aprovechando la fase de burbujeo.

    // HTML: <ul id="lista-tareas"><li>Tarea 1</li><li>Tarea 2</li></ul>
const listaTareas = document.querySelector("#lista-tareas");

listaTareas.addEventListener("click", (e) => {
  // e.target es el elemento exacto donde se hizo click
  if (e.target.matches("li")) {
    e.target.classList.toggle("completada");
    console.log(`Tarea modificada: ${e.target.textContent}`);
  }
});
